# 응대 연습·관찰·용어 검색 변경 기록

2026-09-16. 제품의 중심은 대화 연습 → 근거가 있는 복기 → 같은 장면 재연습이다. 이번 변경은 연습 장면의 발견과 어휘 이해를 돕는다.

## 제공 기능

- 가상 응대 장면 3개: 퇴근 후 반복 연락, 권한 밖 환불·추가 보상 요구, 폭언 상황에서 경계와 도움 요청. 친구방에서 예시를 열고 해당 목표·지킬 선으로 직접 연습한다. 내 대화 카드 3개와 작성 샘플 기록 3개를 추가로 한 번만 시드한다.
- 교사 서우 / 학부모 재이 / 아르바이트생 솔 / 고객 로이: 초대 버튼으로 저장하는 네 역할. 역할은 수정할 수 있고 특정 직업군 전체를 대표하지 않는다. 기존 친구와 사용자 설정을 덮어쓰지 않는다.
- 관찰 베타: 두 캐릭터·주제를 선택해 한 번의 AI 호출로 여섯 발언의 대본을 생성한다. 실제 다중 에이전트 협업은 아니다. 자동 넘기기·일시정지·다음 말·처음부터 제공. AI 오류 시 작성 샘플을 명시적으로 선택할 수 있다. 샘플은 정해진 역할·주제로 돌아가며 개인 페르소나가 적용됐다고 표시하지 않는다. 닫으면 대본은 사라진다.
- 용어 17개 분야·55개 작성 예시. 교육·학부모 응대와 매장·고객 응대 9개 추가. ‘블랙 컨슈머’는 비공식 표현이며 일반적인 불만 제기·환불 요구를 악의로 단정하지 않도록 설명한다.
- 헤더 sticky와 용어·친구방의 compact action bar. 기존 헤더는 스크롤 후 top=-486px로 이탈하는 것을 브라우저 DOM에서 확인했다.

## ‘10대 용어’ 재검토

| 표현 | 반영한 설명 | 분류 판단 |
|---|---|---|
| ㅇㅈ | 채팅에서 ‘인정’의 초성, 공식 응대에서는 인정·동의로 풀어 쓰기 | 온라인 채팅의 작성 예시. 10대만 쓰거나 최신이라는 근거 없음 |
| 찐 | 진짜의 강조. ‘찐 감자’의 ‘찌다’ 활용형 등과 문맥 구별 | 적어도 2020년 방송에도 소개된 기존 표현. 최신 신조어 아님 |
| 꾸안꾸 | ‘꾸민 듯 안 꾸민 듯’, 자연스럽게 보이도록 연출한 스타일 | 스타일·일상 표현. 특정 연령 전용으로 분류할 근거 없음 |
| 최애 | 여럿 중 가장 좋아하는 대상. 사람·음식·노래 등 문맥 확인 | 공공기관의 대국민 안내에도 사용. 10대 전용 분류를 제거 |

분야명은 ‘온라인 · 일상 표현’으로 바꿨다. 뜻을 검토한 것과 표준어 등록·유행 순위 인증은 다르다. 기존 사용자가 편집한 메모는 덮어쓰지 않는다. 하루는 여전히 세대 소통을 연습하는 가상 중학생 AI 역할이며 실존 중학생과 연결하지 않는다.

## 실제 최신 표현 검색

`POST /api/term-trends`: 고정된 한국어·영어·일본어 선택과 전송 동의만 받는다. 개인 원문 등 추가 입력 필드는 모델 요청에 포함하지 않는다. 최근 90일 자료를 우선하고 게시일 미확인을 허용한다. 자동·백그라운드 검색은 없으며 사용자가 누를 때만 호출한다. 기존 Gemini 모델과 키를 사용하며 유료 플랜 가입·변경은 하지 않는다.

[Google의 generateContent 검색 연동 문서](https://ai.google.dev/gemini-api/docs/generate-content/google-search)를 확인해 `google_search`와 검색 메타데이터를 사용했다. Gemini 2.5에서 JSON 응답 형식과 검색 도구를 혼합하지 않는다. 실제 검색어, 원문에 대응하는 출처, 안전한 HTTPS 링크, 정상 완료 상태, Google 검색 제안을 모두 요구한다. 하나라도 확보되지 않으면 최신 목록을 추측해 대신 보여주지 않는다.

응답 원문을 유지하고 제공된 구간에 출처를 표시한다. Google 검색 제안 HTML은 스크립트·동일 출처 권한이 없는 iframe에서 표시한다. [API 약관](https://ai.google.dev/gemini-api/terms)의 검색 결과 표시·저장 제약에 맞춰 공유 캐시·자동 수집·용어 DB 수집·링크 클릭 추적을 하지 않는다. 결과는 해당 요청 화면에만 남는다. 검색 전용 실패는 다른 정상 대화 기능의 재시도를 막지 않는다. 429에는 기존 근거 기반 한도/재시도 안내를 적용한다.

## 검증

82개 테스트: 입력·출처·URL·응답 길이 검증, 개인 정보 추가 필드 미전송, 검색 미지원/근거 없음/429, 검색만 실패한 경우 대화 기능 유지, 두 페르소나와 발언 순서, 샘플 관찰 조작, 삭제된 샘플 미복원·기존 수정 보존을 포함한다. 실제 검색의 가용성과 응답 품질은 운영 배포 후 별도 확인한다. 휴대폰 마이크 품질은 이번 변경 범위 밖이다.
