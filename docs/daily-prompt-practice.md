# 일상 대화와 AI 요청 연습

## 제품 흐름

- 홈의 ‘가볍게 이야기하기’에서 일상·취향·사람 주제를 고르고 최대 세 번 답한다. 친구방에서도 선택한 캐릭터와 시작할 수 있다.
- 기본은 작성된 질문이다. AI 대화는 별도로 선택하고 전송 안내를 확인한다. 작성된 질문과 실제 AI 응답, 장애 시 샘플을 구분한다.
- 마친 뒤 실제 사람에게 건넬 질문을 확인하고, 원하면 자신의 표현을 직접 고친다. 선호 주제는 명시적으로 기억하기를 선택한 경우만 저장한다.
- 최신 화제는 사용자가 검색할 때 공개 주제만 검색한다. 개인 대화나 선호 정보는 검색 요청에 포함하지 않는다. 선택한 검색 결과에는 출처와 검색 시각을 보존한다.
- ‘내 대화 → AI에게 요청하기’에서 가상 회의·고객 응대·제안서 과제를 선택한다. 요청 작성 → 실행 → 출력 확인 → 조건 추가 → 재실행 순서로 연습한다.
- 처음 결과와 최근 결과를 비교한다. 자동 확인은 특정 표현의 존재만 보여주며 사실 정확성이나 품질 점수가 아니다. 작성된 전후 예시는 실제 AI 결과와 분리하고 기록에 저장하지 않는다.

## 저장과 제한

일상 대화와 실제 프롬프트 실행 결과는 현재 브라우저의 IndexedDB에 저장한다. 새로고침 후 대화 기록에서 다시 열 수 있고 삭제할 수 있다. 서버 계정 동기화는 제공하지 않는다. 브라우저 데이터 삭제 시 기록도 사라진다. 전송 전 입력 초안은 자동 저장하지 않는다.

프롬프트 기록은 처음 결과와 최근 네 결과, 최대 다섯 버전을 보존한다. 일상 대화는 자동으로 관심사를 추론하지 않고 보상·연속 출석 점수를 부여하지 않는다. 아침 알림을 발송하거나 앱 밖에서 자동 대화를 시작하지 않는다.

AI 한도·연결 오류가 생기면 일상 대화는 해당 주제의 작성된 응답과 재시도 안내를 표시한다. 프롬프트 연습은 입력과 이전 결과를 유지하고 별도의 예시를 제공한다. 실패를 성공한 AI 결과로 저장하지 않는다.

## 검증

102개 자동 테스트 통과. 새 테스트는 세 번의 일상 대화 저장·재열기, 명시적인 관심사 저장, 한도 초과 시 출처 표시, AI 요청의 자료 격리, 실행 전 후보 수정, 프롬프트 비교·저장·재열기, 화면 주소 복원을 포함한다. AI 제공자는 자동 테스트에서 모의 응답으로 검증한다.

실제 휴대폰 마이크와 음성 인식 품질, 실서비스 AI 출력의 주관적 품질은 별도 기기·운영 검증 대상이다.

## 다음 확장 후보

‘고민 정리’: 선택지 → 중요 기준 → 걱정 → 확인할 정보 → 상대에게 말하기 연습. 결정을 대신 내리는 서비스가 아니라 기존 대화 연습으로 연결하는 방향이며 이번 변경에는 구현하지 않는다.
