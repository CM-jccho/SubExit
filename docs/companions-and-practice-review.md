# 친구방과 대화 복기

기존의 한 번씩 답하는 코칭에서, 사용자가 자기 말을 확인하고 같은 장면을 다시 연습하는 흐름으로 확장했다.

- 기본 친구 네 명(두리·모아·토리·코코)은 이름·모습·색·전문 분야·말투를 수정할 수 있다. 상황별 추천은 명시적인 키워드 규칙이며 AI 추론이라고 표시하지 않는다. 직접 고른 친구는 상황을 수정해도 유지된다.
- 최대 12명의 사용자 친구를 만들 수 있다. 친구방에서 움직이는 친구를 선택하면 개인 기록과 사전 작성 예시를 구분해 보여준다. 움직임 줄이기 설정을 존중한다.
- 직접 대화는 선택한 친구의 역할과 현재 대화만 Gemini에 보낸다. 과거 기록을 새 대화에 자동 삽입하지 않는다. 외부 도구를 실행하는 에이전트는 아니다.
- 새 대화마다 당시 친구 설정을 저장한다. 나중에 친구를 수정해도 기존 기록의 설정은 유지한다. 기존 기록은 당시 설정이 없으므로 상황별 기본 친구로 분류한다.
- 부탁하기 카드 두 개와 대화 예시 두 개를 추가했다. 기존 삭제 내역은 유지하고 새 샘플 묶음은 한 번만 추가한다. 첫 화면은 두 개의 예시만 보여주고 전체 목록으로 연결한다.

## AI 복기 → 다시 연습

1. 개인 연습에서 두 번 이상 답변한 뒤, 전송 안내를 확인하고 ‘AI로 이 대화 복기하기’를 누른다.
2. 현재 카드와 문자만 전송한다. AI가 잘한 점, 개선할 점, 고쳐 말할 문장, 다음 연습 행동을 제시한다.
3. 서버에서 발화 ID가 실제 사용자 발화인지, 인용문이 원문에 존재하는지 검증한다. 없는 근거는 오류로 처리한다. 이 검증은 조언의 의미적 정확성 전체를 보장하지 않으며, UI에 AI 제안임을 표시한다.
4. 결과를 대화와 함께 IndexedDB에 보관한다. 같은 카드·문자 기록에서는 재조회해도 AI를 다시 부르지 않는다. 새 발화나 문자 수정 후에는 새 복기를 요청할 수 있다.
5. ‘이 장면부터 다시 연습’은 개선 대상으로 고른 발화 바로 전까지의 실제 문자 대화를 복사한다. 원래 목표·지킬 선·친구·업종은 유지하며, 음성 원본은 복제하지 않는다. 이어서 새 답변을 보내 연습한다.

## 한도와 저장

Google의 구조화된 quota 위반 정보에서 분당·일일 제한을 구분한다. 근거가 없는 경우에는 원인과 초기화 시간을 확정하지 않는다. 제공된 RetryInfo/Retry-After는 사용자에게 표시하고, 일일 한도가 함께 있으면 일일 초기화 설명을 우선한다. 원문 오류·키·프로젝트 식별자는 공개하지 않는다. 앱 자체 제한은 별도 오류로 표시한다.

요금제나 모델을 자동 변경하지 않는다. 같은 Google 프로젝트의 새 키는 별도 한도를 주지 않는다. 공식 기준: https://ai.google.dev/gemini-api/docs/rate-limits

카드 설정 요청 실패 시 입력과 이전 대화 단계가 복원된다. 연습에서 사용자 답변은 AI 요청 전에 저장하며, 음성 변환 실패 시 원본을 유지한다. 샘플 읽기·기존 음성 재생·직접 메모는 API 호출 없이 가능하다. 데이터는 동일 브라우저에 저장되고 계정 기반 동기화는 제공하지 않는다.

## 검증

자동화 50개 테스트: 기존 녹음/중지 안내·실패 복구·후보 선택·튜토리얼에 더해 캐릭터 저장·수정과 기존 데이터 호환, 샘플 이전, 한도 분류/정보 노출 방지, 대화 API 전송 범위, 복기 근거 검증 및 저장 후 재연습 연결을 확인했다. 타입 검사와 프로덕션 빌드를 포함한다.

실제 모델 출력은 프로젝트의 가용 한도에 영향을 받는다. 실제 휴대폰 마이크와 음성 인식 품질은 별도 기기 검증이 필요하다.
