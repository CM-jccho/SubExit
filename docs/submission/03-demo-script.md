# 90초 시연 대본

## A. 실제 API 연결을 검증한 뒤 사용할 시연

사전 조건: 성인 시연자, 개인정보 없는 자작 대화, API 키와 모델·무료 할당량 확인, 실제 기기 마이크 확인. 음성 재생은 다른 기기에서 한다.

| 시간 | 화면/행동 | 설명 |
|---|---|---|
| 0–15초 | 홈 → 지금 대화 | “영업 전화가 오면 하고 싶은 말을 바로 정리하기 어려운 순간을 돕습니다.” |
| 15–30초 | 상황·전송 안내 확인 → 듣기 | “지금 가입하면 무료인데 왜 안 받으세요?”를 직접 말하거나 다른 기기에서 재생. 실제 마이크 상태를 보여준다. |
| 30–50초 | 인식된 상대 말 확인 → 코칭 | 생성된 한 문장과 실제 원문 근거를 가리킨다. “이 문장을 그대로 따라야 하는 것은 아닙니다. 내 상황에 맞게 골라 말합니다.” |
| 50–65초 | 다른 샘플 문장 직접 입력 | “다른 사람들은 다 가입했어요”로 바꾸고 실제 응답 변화 확인. |
| 65–82초 | 직접 연습 → 내 답변 → 자기 점검 | “대화 전에는 내 말로 한 번 연습하고 고쳐 쓸 수 있습니다. 보상은 참여 기록입니다.” |
| 82–90초 | 프로젝트 안내 | “현재는 짧게 듣고 처리하는 프로토타입입니다. 상시 스트리밍과 단일 기기 통화 연동은 후속 검증 대상입니다.” |

실제 지연에 따라 중간 시나리오를 생략할 수 있다. 처리 시간이 길면 시간을 줄여 말하거나 미리 생성한 것을 실제 응답처럼 보여주지 않는다.

## B. 키 미설정·할당량 소진 시

`/?demo=1`로 진입해 27초짜리 사전 작성 샘플을 보여준다. 화면에 샘플 표기를 유지한다.

“지금 보시는 것은 사전 작성된 흐름 시연입니다. 실제 Gemini 연결 경로는 별도로 구현했지만 오늘은 연결 검증이 되지 않아 실제 응답이라고 주장하지 않습니다.”

이 경우 AI 핵심 기능이 작동하는 시연 증거가 부족하다. 대체 화면은 시연 중단을 막기 위한 수단이며 실제 AI 검증을 대신하지 않는다.

## 체크

- 첫 시연은 영업 전화 거절 한 가지로 좁힌다.
- 샘플 목소리를 실제 고객 통화·실제 녹음이라고 설명하지 않는다.
- API 키와 콘솔 원문 로그를 화면에 노출하지 않는다.
- 실제 Gemini 지연·정확도를 측정하지 않았다면 수치를 말하지 않는다.
