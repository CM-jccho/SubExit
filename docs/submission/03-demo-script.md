# 60초 시연 대본 · v0.3

## 핵심

한 번 만든 내 맥락이 저장·검색·재사용되고 다음 문장에 반영되는 것을 보여준다. 고정 상황이나 XP를 나열하지 않는다.

| 시간    | 화면/행동                                                                             | 설명                                                                                         |
| ------- | ------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 0–10초  | 홈 → 대화 카드 만들기                                                                 | “정해진 상황을 고르기보다 내 이야기를 먼저 합니다.”                                          |
| 10–25초 | '집주인에게 누수 수리 날짜를 정해 달라고 말하고 싶어요' 입력 → 상대·목표·지킬 선 정리 | “상대는 집주인, 목표는 수리 날짜 확정, 지킬 선은 해결 전에 완료됐다고 답하지 않는 것입니다.” |
| 25–35초 | 카드 초안 확인 → 제목 수정 → 저장                                                     | “AI가 추측한 성격이 아니라, 제가 확인한 상황을 남깁니다.”                                    |
| 35–45초 | 내 대화 → '수리' 검색 → 저장 카드 열기                                                | “다음번에는 이 배경을 다시 설명하지 않아도 됩니다.”                                          |
| 45–60초 | 이 카드로 코칭 시작 → 상대 말 입력 → 생성 결과                                        | “상대가 '나중에 보죠'라고 할 때, 목표인 수리 날짜 확정을 함께 참고합니다.”                   |

## 실제 AI 시연 조건

Gemini 키·모델 접근·할당량과 응답을 먼저 확인한다. 무료 시연은 성인 시연자의 개인정보 없는 자작 상황으로 진행한다. 실제 AI 연결 때만 AI 정리를 선택한다. 음성까지 보여주려면 다른 기기에서 샘플 발언을 재생하고 마이크를 미리 확인한다. 처리 시간이 길면 시연 시간을 늘리며, 사전 결과를 실시간 응답처럼 보여주지 않는다.

## 키가 없거나 할당량이 소진되면

카드 작성·저장·검색까지는 질문 안내로 실제 조작한다. “지금은 질문 안내 방식이며 AI 정리는 연결 후 사용할 수 있습니다”라고 설명한다.

코칭 단계는 `/?demo=1`의 마감 조율 예시를 별도로 보여준다. “이 화면은 카드 맥락과 다음 문장의 관계를 보여주는 사전 작성 예시입니다”라고 말한다. 앞서 만든 누수 카드의 AI 결과인 것처럼 설명하지 않는다.

이는 UI와 데이터 흐름의 시연이며 실제 AI 성능의 증거가 아니다. 해커톤 제출 영상 전에 실제 Gemini 초안·코칭 한 건 이상을 검증하는 것이 남은 핵심 작업이다.

## 발표에서 피할 주장

- 상대의 성격이나 심리를 진단한다.
- 같은 휴대폰의 통화를 자동 청취한다.
- 항상 실시간으로 지연 없이 응답한다.
- 카드 사용 횟수가 대화 능력이나 성공률이다.
- 저장만 하면 기기 간에 동기화되거나 모델이 학습된다.
