# v0.3 재구성: 내 상황을 기억하는 대화 코치

## 제품 판단

사용자 피드백: 기능과 고정 상황이 많아 전달하려는 의도가 흐리다. 페르소나와 설정을 대화로 만들고 저장·재사용·검색·데이터화할 수 있는가?

추천: 첫 화면을 '내 대화 카드'로 통일한다. 핵심 데모는 **상황 설명 → 사용자 확인 → 카드 저장 → 저장된 맥락으로 다음 한 문장**이다. 일반 연습 앱이나 모든 통화의 자동 조언 도구라는 설명을 걷어낸다.

| 기존                                    | 이번 변경                                         |
| --------------------------------------- | ------------------------------------------------- |
| 홈에서 연습·실시간·보상·7개 상황 경쟁   | 내 대화 목록 + 새 카드 만들기                     |
| 미리 정한 상대 캐릭터·상황              | 내 역할·상대 역할·실제 상황·목표·지킬 선          |
| 매번 세팅                               | 카드 저장, 수정, 복사, 재사용                     |
| XP가 성과를 대표                        | 메인에서 XP 제거; 실제 카드 사용 맥락만 기록      |
| 화면 설정이 실제 프롬프트와 분리될 위험 | 저장된 카드의 목표와 맥락을 서버 코칭 요청에 전달 |

**페르소나는 상대를 진단하는 성격 유형이 아니다.** 사용자가 알려준 관계·역할과 내 목표를 담는다. 새 상황을 기존 카테고리로 분류할 필요가 없다. 집주인에게 수리 날짜 요청, 담당자에게 진행 상황 확인 같은 자유로운 상황을 만들 수 있다.

## 화면

1. 내 대화: 새 카드 만들기, 저장 목록, 상대·상황·목표 검색.
2. 카드 만들기: 대화로 설명하거나 직접 작성. 정리 초안을 사용자가 수정·확인한 뒤 저장.
3. 카드 상세: 저장된 맥락 확인, 수정, 복사, 삭제, 코칭 시작.
4. 코칭: 선택한 카드를 바탕으로 텍스트/최대 8초 마이크 입력에 대응.

연습은 `/practice`의 보조 링크로 이동했다. `/?demo=1`은 대화 카드와 맞춤 문장의 관계를 보여주는 명시적 샘플이다. `/?live=1`은 카드 선택부터 시작한다.

## 대화형 설정의 두 방식

- 질문 안내: API 키 없이 상황·상대·목표·지킬 선을 직접 답한다. 결과는 사용자가 쓴 문장을 구조화한다. AI 생성이라고 표시하지 않는다. 어느 단계에서든 직접 수정할 수 있다.
- AI 정리: Gemini 연결과 전송 확인 후, 자유 대화를 읽어 카드 필드를 정리하고 중요한 누락 한 가지를 묻는다. 알고 있는 내용을 반복 질문하거나 성격을 추측하지 않게 지시한다. 저장 전 사용자가 확인한다.

현재 운영 키 연결은 확인되지 않았으므로 AI 정리와 실제 코칭의 품질 검증은 별도다. 질문 안내와 카드 저장은 외부 AI 없이 동작한다.

## 저장 모델

`id, title, myRole, partner, situation, goal, boundaries, tone, source, createdAt, updatedAt, lastUsedAt, useCount`.

- localStorage에 확인된 카드만 저장. 최대 100개.
- 설정 대화 전문·통화 원문·음성·AI 응답은 카드 데이터에 저장하지 않는다.
- 사용 횟수는 코칭 화면을 연 횟수이며 성공·효과·실제 AI 사용 횟수가 아니다.
- 검색은 위 텍스트 필드의 여러 검색어를 모두 포함하는 카드만 찾는다.
- JSON 내보내기는 로컬 파일 다운로드. 계정/서버 동기화나 모델 학습은 구현하지 않았다.
- 저장 오류 시 저장 성공으로 표시하지 않는다. 시크릿 모드·브라우저 데이터 삭제·다른 기기에서는 기록이 유지되지 않을 수 있다.
- 카드 내용 자체에 개인정보가 들어갈 수 있다. 실명 대신 역할을 쓰도록 안내하며, 무료 Gemini로 보내는 경우 개인정보·기밀 없는 샘플만 사용한다.

## 해커톤에서 보여줄 60초

0–15초: '집주인에게 누수 수리 날짜를 확정받고 싶다' 등 정해져 있지 않은 상황을 설명.
15–30초: 상대·목표·지킬 선으로 정리된 카드 확인/수정 후 저장.
30–40초: 홈으로 돌아와 '수리'로 검색하고 저장 카드를 다시 연다.
40–60초: 실제 키로 상대의 말을 입력하고 목표에 맞는 멘트 생성. 키가 없으면 명시적인 사전 작성 예시로만 설명하고 AI 실증으로 주장하지 않는다.

## 후속 옵션 (미구현)

A. 예선 추천: 현재 기기 내 카드 저장과 단일 사용자 흐름.
B. 사용자 검증 후: 로그인 + 기기 간 동기화, 보존/삭제 정책, 카드별 익명화된 결과 회고.
C. 반복 가치 검증 후: 카드 버전 이력과 어떤 맥락/수정이 유용했는지 사용자가 남기는 피드백.

무작정 대화를 쌓는 것보다 '어떤 목표의 카드를 다시 꺼냈는가'가 초기 데이터다. 데이터 수집이 모델 개선이나 수요 검증을 자동으로 의미하지는 않는다.

## 구현 검증

자동 테스트 20개, 타입 검사, production build 통과. 카드 스키마/저장 실패/정체성 보존/검색/재사용과 사용자 정의 맥락의 서버 전달을 검증했다. AI 정리의 동의·미연결·출력 검증은 모의 제공사로 확인했다. 실제 키의 품질과 모바일 마이크는 미검증이다. 카드 확인은 대화 화면과 분리하고 모바일 입력 글자를 16px로 설정했다.
