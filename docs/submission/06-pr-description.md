# 대화로 만드는 맥락 카드와 저장·검색·재사용 흐름

고정 상황과 연습·보상이 홈에서 경쟁해 제품의 목적이 흐려졌습니다. 첫 화면을 '내 대화'로 좁히고 사용자 자신의 상대·상황·목표를 저장해 코칭에 재사용하도록 바꿉니다.

## 변경

- 대화 안내/선택적 Gemini 정리 → 별도 카드 확인 화면 → 로컬 저장.
- 카드 수정·복사·삭제·여러 검색어 검색·JSON 내보내기, 사용 메타데이터.
- 저장된 맥락을 코칭 서버에 전달. 고정 시나리오로 분류할 필요 없음.
- 홈에서 XP와 고정 메뉴 제외. 기존 연습은 `/practice`로 이동.
- AI 미연결·사전 작성 예시·기기 내 저장을 명확히 표시.
- 제출 문안·60초 대본·데이터 모델 문서 정렬.

## 검증과 한계

20개 테스트, 타입 검사, production build 통과. 저장 실패, 필드 검증, 맥락 전달, AI 동의와 실패 경로를 검증했습니다. 실제 Gemini 품질·음성 정확도·iPhone 마이크는 키/기기가 없어 미검증입니다. 계정 동기화 없이 브라우저에 확인된 카드만 저장합니다. 설정 대화 전문은 저장하지 않습니다.
