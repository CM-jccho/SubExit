# 든든콜: 실제 대화 보조 중심 UX 및 Gemini 무료 시연 경로

기존 화면은 연습·녹음 분석·실시간 코치의 경계가 흐렸고, 사전 작성 결과가 실제 분석이나 개인 성과처럼 보일 수 있었습니다. 부담스러운 대화에서 바로 쓸 한 문장을 찾는 목적에 맞춰 홈과 코칭 흐름을 정리합니다.

## 변경

- 지금 대화 최우선 홈, 7개 상황 연습, 자기 점검/고쳐 쓰기/복기.
- 말해보카의 짧은 학습 흐름을 참고한 UI. 밝은 바탕과 짙은 녹색 코칭 영역, 모바일 하단 메뉴.
- 최대 8초 마이크 입력 → Gemini 전사 → 확인/자동 코칭. 처리 중 마이크 해제, 탭 비활성화와 요청 취소 처리.
- Gemini 서버 전용 키, 무료 샘플 전송 조건, 원문 인용 검사, 크기·시간·요청 제한.
- 참여 보상 중복 방지. 샘플에 점수나 능력 평가를 부여하지 않음.
- 기존 가짜 음성 분석 경로 중단. Next.js 15.5.25로 업데이트.
- 기획 검토/제출 문안/시연 대본/검증/Gemini 가이드 포함.

## 검증

14개 자동 테스트와 production build 통과. 실제 Gemini 키·음성 품질·휴대폰 마이크·새 화면 시각 QA는 미완료입니다. 모의 제공사 테스트는 실제 LLM 품질을 보장하지 않습니다.

## 리뷰 시 확인

기존 analyze-call 응답 계약은 호환하지 않습니다. 보존된 UploadForm은 새 루트에서 사용하지 않습니다. 인스턴스별 rate limit은 공개 배포 전체 한도가 아닙니다. 미리보기에서 실제 키/샘플 음성/모바일 UI 확인 후 병합 여부를 결정합니다.
