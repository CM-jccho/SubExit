# 스픽코칭 · 제출 입력 문안

작성 기준: 2026-09-18. 이 문서는 복사 가능한 문안입니다. 제출 양식의 실제 글자 수 제한은 로그인 후 확인해야 합니다. 기능 설명과 검증 상태를 함께 읽어 주세요.

## 서비스명 / 제출 제목

스픽코칭 — 말이 막히는 순간, 내 뜻을 전하는 AI 대화 코치

## 한 줄 소개

부탁·거절·일정 조율이 어려운 순간, 내 상황과 목표, 지킬 선을 바탕으로 다음 한마디를 찾고 연습하는 AI 대화 코칭 서비스입니다.

## 짧은 서비스 소개

할 말은 있지만 어떻게 꺼낼지 막히는 사람을 위한 서비스입니다. 대화 전에는 상대와의 대화를 연습하고, 대화 중에는 상대의 말에 맞는 다음 한마디를 참고하며, 대화 후에는 녹음과 문자를 돌아봅니다. 유창한 말보다 내 뜻과 경계를 지키며 말하는 경험을 돕습니다.

## 해결하고자 한 문제

부탁이나 거절, 업무·약속 조율에서는 단순히 공손한 문장만으로 충분하지 않습니다. 상대와의 관계, 내가 원하는 결과, 양보하지 않을 선을 함께 고려해야 합니다. 그러나 긴장하거나 즉시 답해야 할 때는 이 조건들을 떠올리고 문장으로 만들기 어렵습니다.

스픽코칭은 사용자가 먼저 상황·목표·지킬 선을 정리하도록 돕고, 그 맥락을 대화 연습과 다음 한마디 제안에 이어 사용합니다. 추천을 그대로 외우게 하기보다 자신의 말로 고쳐 쓰고 다시 시도할 수 있도록 설계했습니다.

## 누구에게 어떤 도움을 주나요?

- 부탁과 거절을 미루는 사람: 관계를 존중하면서 요청과 경계를 말하는 연습.
- 직장 대화가 부담스러운 사람: 일정·우선순위·담당 범위를 구체적으로 조율하는 문장.
- 고객 응대가 어려운 사람: 요구를 확인하면서 감당할 범위와 도움 요청을 표현하는 연습.
- 일상에서 말이 막히는 사람: 가족·친구와의 대화에서 자신의 목표를 정리하고 다음 말을 준비하는 도움.

## 핵심 기능

1. **대화 전, 미리 연습하기**: 상대와 상황을 고르고 목표에 맞는 답변 후보를 참고하거나 직접 답합니다. 대화를 돌아보고 같은 장면에서 다시 말해봅니다.
2. **대화 중, 다음 한마디**: 상대의 말을 문자 또는 지원 브라우저의 음성 입력으로 전달하면 맥락에 맞는 짧은 답변을 제안합니다. 직전 추천 두 개를 같은 화면에 남겨 비교하고 다시 볼 수 있습니다.
3. **대화 후, 녹음 분석·코칭**: 직접 녹음하거나 음성·자막 파일을 가져옵니다. 변환 문자와 말한 사람, 목표를 확인한 뒤 코칭을 요청합니다. 용어와 표현은 내 노트에 모아봅니다.

## AI 활용 방식 및 결과

서비스 AI에는 Google Gemini 2.5 Flash를 사용합니다. 입력된 상대의 말과 상황·목표·지킬 선을 함께 전달해 다음 한마디, 역할 대화 응답, 대화 복기와 용어 설명을 생성합니다. 음성 파일을 문자로 바꾸는 경로에도 Gemini를 사용합니다. 지원 브라우저에서는 브라우저 음성 인식으로 중간 자막을 표시하고, 문자 확정과 AI 제안을 별도로 처리합니다.

코드에서는 출력 형식과 필수 항목, 일부 코칭 응답의 원문 인용을 검사합니다. 이는 오류를 줄이는 장치이며 생성 내용의 정확성을 보증하지는 않습니다. 사용자는 인식된 문자와 답변을 직접 수정할 수 있습니다. AI 호출 없이 흐름을 체험하는 사전 작성 샘플은 별도 표시합니다.

개발 과정에서는 ChatGPT(Codex)를 요구사항 정리, UI·코드 구현, 회귀 테스트 작성과 오류 분석에 활용했습니다. 대표 소개 이미지는 AI 이미지 생성으로 제작했습니다. 현재 자동 테스트 192개와 프로덕션 빌드가 통과했으며, 테스트에는 외부 AI·미디어 대역이 포함됩니다. 실제 사용자 효과나 전체 기기 호환성은 아직 검증한 수치가 없습니다.

## 차별점과 발전 방향

상황·목표·지킬 선을 공통 맥락으로 삼아 연습, 대화 중 도움, 대화 후 돌아보기를 연결한 점에 초점을 맞췄습니다. 다음 단계에서는 실제 사용자의 대화 과제 완료 여부, 첫 유효 제안까지의 시간, 추천 수정 비율을 측정할 계획입니다. 장기 학습 효과나 의사소통 능력 향상을 이미 입증했다고 표현하지 않습니다.

## 서비스 범위와 데이터 안내

현재 구현은 모바일·데스크톱 웹입니다. 실제 통화 오디오를 자동 수집하거나 모든 브라우저에서 끊김 없이 실시간 통역하는 제품은 아닙니다. 브라우저 음성 인식이 제한되면 짧게 녹음한 뒤 문자로 바꾸거나 직접 입력합니다. 파일 입력은 최대 30분·50MB이며, 긴 음성은 45초 단위로 준비해 처리합니다. TXT/SRT/VTT도 가져올 수 있습니다.

기록은 브라우저 저장소에 남으며 다른 기기나 도메인으로 자동 동기화되지 않습니다. AI 기능에는 동의한 음성·문자 등 필요한 입력을 Gemini로 전송합니다. 브라우저 음성 인식은 브라우저 제공자의 처리가 개입할 수 있습니다. 전부 기기 안에서만 처리된다고 설명하지 않습니다. 데모에는 개인정보·기밀 없는 가상 상황만 사용합니다.

실제 코칭 입력은 개인정보 없는 “왜 이제 약속을 바꾸자는 거야?”였습니다. 출력은 “미안해. 갑자기 변경하게 됐는데, 혹시 일요일 오후는 괜찮을까?”였습니다. 서버가 보고한 생성 시간은 1,742ms, 클라이언트 전체 왕복은 12.04초였습니다. 한 번의 측정이며 평균·일반 성능으로 쓰지 않습니다. 네트워크·플랫폼 경유 시간을 포함한 지연 원인은 이 결과만으로 특정할 수 없습니다.

용어 요청은 “SLA와 API 응답 시간을 확인해 주세요.”라는 가상 문장입니다. 서비스의 재시도 안내는 2026-09-18 한국 시간 오후 4시 이후입니다. 한도가 반드시 그 시점에 복구된다는 별도 운영 보증은 없습니다. 호스팅을 Vercel로 바꿔도 같은 Google 프로젝트 한도는 해결되지 않습니다.

원 응답과 소요 시간은 `deployment-check.json`에 있습니다. 사용자 음성이나 개인 대화는 검증에 전송하지 않았습니다.

# 기존 Vercel 주소 배포 확인

## 결론

현재 Next.js 소스는 Vercel 배포를 검토할 수 있는 구조입니다. 그러나 **wanted-sidecue 기존 프로젝트에 현재 연결 계정으로 접근할 때 403 Forbidden**이 반환되어 최신 소스를 배포하지 못했습니다. 기존 주소의 API 설정 조회 여부와 최신 배포 여부는 별개입니다.

형식 확인용 불완전 배포 요청은 자동 승인 검토에서 거절되었습니다. 이유는 미확인 배포 대상과 불완전한 파일 목록이었으며, 그 요청으로 배포가 실행되지는 않았습니다. 이후 실제 기존 프로젝트 조회에서도 권한 부족이 확인되어 배포를 우회하지 않았습니다.

GitHub의 9월 17일 기존 Vercel 상태에는 배포 횟수 제한 기록도 있습니다. 이는 과거 상태이며 현재 제한 지속 여부를 확정한 것은 아닙니다.

## 준비된 최종 소스

- 저장소: https://github.com/CM-jccho/SubExit
- 소스 브랜치: `deploy-render-20260917`
- UI 수정 코드 커밋: `83c7f01b9e9cd661e041a99be7476ce4179ab99d`
- Next.js 15.5.25, Node >=20.9, `npm ci`, `npm run build`
- 최신 수정본은 두 Render 서비스에서 live 상태 확인.

## 기존 프로젝트 소유 계정에서 이어서 할 일

1. `wanted-sidecue`를 소유한 Vercel 팀 계정으로 연결합니다. 확인된 팀 슬러그는 `jojos-projects-ae81ae4b`입니다.
2. 기존 프로젝트의 Git 저장소와 Production Branch를 확인합니다. 위 소스 브랜치의 코드 커밋이 포함되어야 합니다. 예전 배포의 Redeploy만 누르면 예전 소스를 다시 올릴 수 있습니다.
3. 기존 환경 변수 설정을 확인합니다. 비밀 키를 문서나 채팅에 복사하지 않습니다.
4. 정확한 최신 커밋으로 Production 배포 후 wanted-sidecue.vercel.app 연결을 확인합니다.
5. 첫 방문, 실제 AI 요청, 음성 입력 대체 경로, 기록 저장을 그 주소에서 다시 검증한 뒤 제출 링크를 바꿉니다.

## 환경 변수 확인

| 이름 | 확인할 내용 |
|---|---|
| GEMINI_API_KEY | 소유 프로젝트의 유효한 키. 클라이언트 번들에 넣지 않음 |
| GEMINI_MODEL | 현재 기본 모델 gemini-2.5-flash |
| COACH_AI_ENABLED / COACH_VOICE_ENABLED | false이면 해당 기능이 꺼지므로 운영 의도 확인 |
| GEMINI_DATA_MODE | 실제 API 결제·데이터 조건과 일치하는 free/paid 설정. 값을 바꿔도 결제 계정이나 쿼터가 바뀌지 않음 |

호스팅 변경은 Gemini 사용량 한도를 초기화하지 않습니다. 대용량 원본 파일은 브라우저에서 작은 음성 구간으로 준비해 전송하지만 긴 파일·서버리스 시간 제한 경로는 새 배포에서 확인해야 합니다. 현재 프로세스 메모리의 요청 제한은 여러 서버 사이에 공유되는 전역 제한이 아닙니다.

## 주소 변경 시 기록

Render와 Vercel은 출처(origin)가 달라 브라우저 저장소가 분리됩니다. 기록을 자동 이전했다고 안내하지 마세요. 내보내기 가능한 기록을 보관하고, 새 주소에서는 필요한 상황을 다시 확인해야 합니다.
