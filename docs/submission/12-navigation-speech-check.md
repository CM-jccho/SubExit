# 탐색·실시간 자막 후속 점검 — 2026-09-18

## 변경

- 답변 추천받기의 실시간 자막 탭은 동의 전에도 열립니다. 음성 전송은 AI 동의와 브라우저 음성 전송 동의를 모두 확인한 후 사용자가 듣기 시작을 눌러야 시작합니다.
- 탭 진입을 막던 음성 파일 변환 가능 여부 조건을 제거했습니다. 브라우저 자막 인식과 Gemini 음성 파일 변환은 서로 다른 경로입니다. 실제 시작은 AI 연결 상태를 확인합니다.
- 대화 연습의 ‘다른 기능으로 이동’은 안내 문구에서 클릭 가능한 펼침 메뉴로 변경했습니다.
- 홈에서 내 대화 돌아보기에 들어오면 ‘홈으로’, 연습 목록에서 들어오면 ‘연습 상황 목록으로’ 표시와 동작을 일치시켰습니다. 기존 기록을 열 때는 ‘내 기록으로’를 유지합니다.
- 음성 인식 엔진 생성 실패를 처리하고, 마이크 입력 실패·언어 미지원·권한·네트워크 오류를 구분합니다. 인식 시작 후 15초간 자막이 없거나 no-speech 오류가 발생하면 확인할 내용을 안내합니다.
- ‘자막을 직접 입력으로 이어가기’는 인식을 중지하고 확정·임시 자막을 기존 입력 다음 줄에 옮깁니다. 자동 AI 요청은 하지 않습니다.

## 검증 범위

자동화는 모의 음성 인식 이벤트를 사용합니다. 홈/연습 목록/내 기록 복귀, 펼침 메뉴 이동, 동의 전 탭 진입과 마이크 차단, 자막 무응답 안내, 생성 실패, 자막→직접 입력 보존을 확인합니다. 결제·실제 음성은 자동화에 포함하지 않습니다.

검증용 브라우저는 탭 연결 시간 초과로 접근하지 못했습니다. 사용자 기기의 실시간 인식 실패 원인은 아직 확정하지 못했고, 실제 마이크 정상 동작을 확인했다고 주장하지 않습니다.

## 마지막 실제 기기 확인

1. 새로고침 → 답변 추천받기 → 실시간 자막. 동의하지 않아도 설정 화면을 열 수 있어야 합니다.
2. 두 전송 동의 확인 → 실시간 듣기 시작 → 사이트 마이크 허용. ‘내일 약속 시간을 바꿀 수 있을까?’를 말합니다.
3. 자막이 나타나는지 먼저 확인하고, 별도로 AI 코칭 성공/한도 오류를 확인합니다. AI 한도 오류로 자막까지 멈췄다고 판단하지 않습니다.
4. 듣기 멈춤 후 새 말이 추가되지 않는지 확인합니다.
5. 네트워크·권한 오류 시 안내가 보이는지, 직접 입력으로 이어가기에 기존 자막이 남는지 확인합니다.
6. 문제가 남으면 기기·브라우저 이름과 ‘버튼 비활성/연결 중/듣는 중이나 자막 없음/오류 문구’ 중 어떤 상태인지 기록합니다.
