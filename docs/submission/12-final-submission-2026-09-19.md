## 1. 제출 제목

**스픽코칭 — 말이 막히는 순간, 다음 한마디를 돕는 AI 대화코치**

대안:
- 스픽코칭 — 말로 연습하고, 실전에서 도움받고, 다시 말해보는 AI 대화코치
- 스픽코칭 — 답을 대신 써주는 AI를 넘어, 내가 직접 말할 수 있게 돕는 AI

메인 타이틀은 첫 번째 안을 권장한다. Voice-first는 메인 제목보다 제품 차별화 설명에서 사용한다.

## 2. 한 줄 소개

**부탁·거절·일정 조율처럼 말이 막히는 순간, 상대의 말과 내 목표를 바탕으로 다음 한마디를 제안하고, 대화 전 연습부터 실제 대화 복기와 재연습까지 ‘말’로 이어주는 AI 대화 코칭 서비스입니다.**

짧은 버전:

**말로 연습하고, 실전에서 다음 한마디를 도움받고, 실제 내 말을 복기해 다시 말해보는 AI 대화코치입니다.**

# 3. 제출 이미지 구성

권장 구성은 **대표 이미지 1장 + 기능 이미지 4장, 총 5장**이다.

이미지의 역할은 기능 수를 보여주는 것이 아니라 하나의 대화가 **BEFORE → LIVE → AFTER → RETRY**로 이어지는 것을 증명하는 것이다.

## IMAGE 01 · 메인 스크린 / 대표 이미지

### 목적
심사위원이 첫 3초 안에 “무슨 서비스인지” 이해하게 한다.

### 실제 캡처 상태
https://speakcoaching-one.vercel.app/ 홈 화면에서:
- 스픽코칭 브랜드
- **말이 막히는 순간, 바로 옆에서**
- **다음 한마디가 필요할 때, 스픽코칭**
- 한 장면 예시
  - 상대: “왜 미리 말 안 했어요?”
  - 스픽코칭: “제가 먼저 공유했어야 했어요. 지금 상황부터 바로 말씀드릴게요.”
- **지금 대화 도움받기** CTA

### 이미지 상단 설명 문구
**말이 막히는 순간, 다음 한마디.**

### 이미지 하단 설명 문구
**답을 대신 써주는 AI를 넘어, 내가 직접 말할 수 있게 돕는 AI 대화코치**

### 제출 설명
> 실제 사람과 대화할 때 가장 어려운 순간은 채팅창에 글을 쓰는 때가 아니라 바로 대답해야 하는 순간이었습니다. 스픽코칭은 상대의 말과 내가 원하는 결과를 바탕으로, 지금 이어서 말할 수 있는 짧은 한마디를 제안합니다.

## IMAGE 02 · LIVE / 지금 대화 도움

### 목적
스픽코칭의 첫 번째 차별화인 **WHAT TO SAY — 실제 대화 중 다음 한마디**를 증명한다.

### 실제 캡처 상태
지금 대화 도움받기 진입 후:
- 들려주기 / 직접 입력 / 실시간 자막 탭
- 직접 입력 또는 실제 음성 입력으로 상대 말 입력
- AI 실제 결과
- 결과 영역에 **지금 필요한 한마디 / 다음 한마디**
- **부드럽게 / 분명하게 / 짧게** 버튼

추천 가상 입력:
- 상대: “왜 미리 말 안 했어요?”
- 목표: 상황을 설명하고 다시 일정을 합의하기
- 지킬 선: 확정되지 않은 완료 시간을 약속하지 않기

### 이미지 제목
**LIVE · 실제 대화에서 다음 한마디**

### 이미지 설명
> 상대의 말을 음성이나 글로 전달하면, 현재 상황·목표·지킬 선을 반영한 다음 한마디를 제안합니다. 같은 내용도 ‘부드럽게 / 분명하게 / 짧게’ 다시 요청할 수 있습니다.

## IMAGE 03 · VOICE / 실시간 자막 + 다음 한마디

### 목적
텍스트 챗봇과 다른 스픽코칭의 **Voice-first 경험**을 보여준다.

### 캡처 조건
반드시 실제 동작이 확인된 브라우저에서 캡처한다.
- 실시간 자막이 실제로 들어오는 상태
- 계속 듣고 있어요 상태
- 인식 자막
- AI의 다음 한마디
- 실제 AI 결과이면 AI 제안 표시

iPhone에서 실시간 자막이 불안정하면 제출 이미지 때문에 연출하지 않는다. 정상 동작하는 지원 브라우저에서 실제 인식 화면을 캡처한다.

### 이미지 제목
**VOICE · 듣고, 이해하고, 바로 이어 말하기**

### 이미지 설명
> 지원 브라우저에서는 상대의 말을 자막으로 확인하면서 확정된 문장을 바탕으로 AI 코칭을 갱신합니다. 같은 휴대폰의 통화 음성을 직접 가져오는 방식이 아니라, 대면 대화나 다른 기기의 스피커폰 옆에서 사용하는 보조 경험입니다.

### 핵심 메시지
**AI에게 글을 써 달라고 요청하는 것이 아니라, 실제 대화 중 내가 직접 말할 수 있도록 돕는다.**

## IMAGE 04 · BEFORE / 말로 미리 연습

### 목적
실시간 기능 하나로 끝나는 서비스가 아니라는 것을 보여준다.

### 실제 캡처 상태
대화 전 · 미리 연습하기.

추천 장면:
- 상황: 팀장에게 현재 일정으로는 금요일 완료가 어렵다고 설명하고 우선순위를 조율해야 한다.
- AI 상대가 한 문장을 말한 상태
- 사용자가 음성 또는 직접 답변을 한 상태
- 가능하면 두 턴 이상

### 이미지 제목
**BEFORE · 중요한 대화는 먼저 말해보기**

### 이미지 설명
> 같은 상대·상황·목표를 가지고 AI가 대화 상대 역할을 맡습니다. 정답 문장을 외우는 연습보다, 사용자가 직접 답하고 실제로 입 밖으로 말해보는 연습에 초점을 맞췄습니다.

## IMAGE 05 · AFTER + RETRY / 실제 내 말 복기

### 목적
스픽코칭의 두 번째 차별화인 **Voice Loop**를 완성한다.

### 실제 캡처 상태
내 대화 복기 화면에서:
- 사용자의 실제 발화
- 다음에는 이렇게 말해보세요
- 내 말에서 근거 보기
- 고쳐볼 표현
- 잘한 점
- **이 장면부터 다시 연습** 버튼

### 이미지 제목
**AFTER → RETRY · 실제 내 말을 복기하고 같은 장면 다시 말하기**

### 이미지 설명
> 스픽코칭은 AI의 추천만 보여주고 끝나지 않습니다. 실제 내가 한 말을 근거로 잘한 점과 바꿔볼 표현을 확인하고, 그 장면부터 다시 연습합니다.

### 핵심 문장
**연습 → 실전 → 복기 → 다시 연습**

# 4. 다섯 이미지를 하나의 이야기로 읽게 만드는 캡션

1. **말이 막히는 순간, 다음 한마디**
2. **LIVE · 실제 대화에서 지금 필요한 한마디**
3. **VOICE · 상대 말을 듣고 자막과 코칭으로 이어가기**
4. **BEFORE · 중요한 대화는 말로 먼저 연습**
5. **AFTER → RETRY · 실제 내 말을 복기하고 같은 장면 다시 연습**

# 5. 제품 차별화 설명

## 핵심 차별화 1 · WHAT TO SAY
**무슨 말을 할지**
- 상대 말 이해
- 상황·목표·지킬 선 반영
- 지금 필요한 다음 한마디
- 부드럽게 / 분명하게 / 짧게 변형
- 실제 내 말 근거로 복기

## 핵심 차별화 2 · HOW TO SAY IT
**내가 직접 말할 수 있게**

현재 구현:
- 음성으로 AI 상대와 대화 연습
- 짧은 상대 말 녹음 → 문자 변환 → 코칭
- 지원 환경에서 실시간 자막
- 실제 대화 녹음 첨부 및 복기
- 같은 장면 다시 연습

향후 확장:
- 말속도
- 긴 쉼
- 필러워드
- 발화 길이
- 억양 변화
- 음량 안정성
- 연습 전후 변화

이번 제출에서는 향후 항목을 이미 구현된 기능처럼 설명하지 않는다.

# 6. 해결하고자 한 문제

> ChatGPT에게 좋은 문장을 만들어 달라고 할 수는 있습니다. 하지만 실제 사람 앞에서는 결국 내가 직접 말해야 합니다.
>
> 부탁을 거절하거나, 일정 변경을 설명하거나, 상사·고객과 조율해야 하는 순간에는 상대의 말에 즉시 반응하면서 내 목표와 지킬 선도 함께 떠올려야 합니다. 긴장한 상황에서는 이것을 동시에 하기 어렵습니다.
>
> 스픽코칭은 이 문제를 하나의 대화 흐름으로 해결하려 했습니다. 대화 전에는 말로 연습하고, 실제 대화 중에는 상대 말을 바탕으로 다음 한마디를 도움받고, 대화 후에는 실제 내 말을 복기해 같은 장면을 다시 연습합니다.

# 7. AI 활용 방식

> Google Gemini 2.5 Flash를 사용해 상대 발화와 사용자가 정한 상황·목표·지킬 선을 함께 이해하고, 짧은 다음 한마디, 역할 대화 응답, 실제 대화 복기와 음성 문자 변환을 생성합니다.
>
> 짧은 음성 입력은 MediaRecorder로 캡처한 뒤 Gemini로 문자 변환하고, 지원 브라우저에서는 Web Speech API 기반 자막을 별도로 표시합니다. 실시간 자막의 확정 문장을 바탕으로 코칭 요청을 갱신하며, 자막 표시와 AI 생성은 분리해 처리합니다.
>
> AI 출력은 필요한 구조와 원문 인용 여부를 코드에서 검사하고, 사용자가 인식 문자와 제안을 직접 확인·수정할 수 있게 했습니다. AI 호출에 실패하면 실제 결과처럼 샘플을 자동 대체하지 않고, 사전 작성 샘플은 별도 체험으로 구분합니다.
>
> 개발 과정에서는 ChatGPT/Codex를 요구사항 구조화, 구현, 코드 리뷰, 회귀 테스트, 오류 분석과 UI 개선에 활용했습니다.

# 8. 구현 결과

> 모바일·데스크톱 웹으로 구현해 Vercel Production에 배포했습니다.
>
> 핵심 흐름은 **BEFORE → LIVE → AFTER → RETRY**입니다.
>
> - BEFORE: AI 상대와 말로 미리 연습
> - LIVE: 상대 말을 음성·문자·지원 환경의 실시간 자막으로 전달하고 다음 한마디 확인
> - AFTER: 실제 대화 녹음·문자를 기반으로 내 말 복기
> - RETRY: 개선이 필요한 장면부터 다시 연습
>
> 실제 통화 오디오를 같은 휴대폰에서 자동 수집하는 방식은 아니며, 실시간 자막은 브라우저 지원 범위에 따라 제한될 수 있습니다. 지원되지 않는 경우 짧게 녹음하거나 직접 입력하는 경로를 제공합니다.

# 10. 차별점

일반적인 AI 말하기 서비스가 **녹음 → 음성 평가 → 점수/피드백**에 집중한다면, 스픽코칭은 한 사람의 실제 대화 상황을 다음처럼 연결한다.

**말로 미리 연습**
→ **실전 대화를 듣기**
→ **지금 필요한 다음 한마디**
→ **실제 내 말 복기**
→ **같은 장면 다시 말하기**

즉 Voice는 부가 기능이 아니라 준비부터 실전·복기까지 제품 전체를 이어주는 인터페이스다.

> “끝난 뒤에는 AI 문장이 아니라 실제 내가 한 말을 근거로 복기합니다.”

## 50–57초 · RETRY
이 장면부터 다시 연습 클릭.

내레이션:
> “그리고 어려웠던 바로 그 장면을 다시 말해봅니다.”

## 57–60초 · Ending

> **말로 연습하고, 실전에서 도움받고, 다시 말해보세요.**
>
> **스픽코칭**

# 13. 심사 항목과 연결

## 기획력
실제 대화에서 ‘바로 말해야 하는 순간’이라는 구체적인 문제를 정의하고, 단순 텍스트 생성이 아닌 BEFORE → LIVE → AFTER → RETRY 경험으로 구조화했다.

## 실현 가능성
음성 녹음, 음성 문자 변환, 실제 AI 코칭, 역할 대화, 녹음 복기와 재연습을 하나의 웹 서비스로 구현했다. 브라우저 제약이 있는 기능에는 직접 입력·짧은 녹음 대체 경로를 둔다.

## 확장성
현재는 WHAT TO SAY 중심이며, 이후 HOW TO SAY IT 영역에서 말속도·긴 쉼·필러·발화 길이 등 실제 발화 행동 데이터로 확장할 수 있다.

## AI 활용 적절성
AI를 장식적인 챗봇으로 사용하지 않고, 음성 문자 변환, 상황 맥락 이해, 다음 한마디 생성, 역할 대화, 근거 기반 복기라는 핵심 경험에 사용한다.

# 14. 제출에서 피할 표현

- 전화 통화를 자동으로 듣습니다.
- 모든 브라우저에서 실시간으로 동작합니다.
- 상대의 감정이나 심리를 정확하게 분석합니다.
- AI가 사용자의 커뮤니케이션 능력을 객관적으로 점수화합니다.
- 목소리로 자신감을 정확히 측정합니다.
- 사용하면 대화 능력이 향상됩니다.
- 음성은 모두 기기에서만 처리됩니다.
- 사전 작성 샘플을 실제 AI 결과처럼 설명하는 표현
