# Gemini 무료 API 예선 운영안

## 결론

제한된 성인 대상·개인정보 없는 샘플 시연에는 Gemini API 무료 티어를 사용할 수 있다. 일반 사용자의 실제 통화를 상시 처리하는 운영 기준으로는 무료라는 이유만으로 적합하다고 판단하지 않는다. Gemini 일반 웹앱 무료 사용과 개발자 API의 무료 할당량은 별개다.

현재 기본 모델은 `gemini-2.5-flash`. 코드에 고정된 선택을 바꾸려면 `GEMINI_MODEL` 환경변수와 해당 모델의 구조화 출력·음성 지원·계정 접근 여부를 함께 확인한다.

## 사용량 구조

- 텍스트 코칭 1회 = generateContent 1회.
- 음성 입력 후 코칭 1회 = 전사 1회 + 코칭 1회, 총 2회.
- 샘플 시연/직접 답변 연습 = API 호출 없음.
- 음성은 최대 8초. 한 파일을 완성한 뒤 요청하며 지속 업로드하지 않음.
- 429는 한도 초과 안내. 다른 유료 모델로 자동 전환하지 않음.

정확한 RPM/RPD는 모델·계정·티어에 따라 달라지므로 고정 수치를 약속하지 않는다. [AI Studio](https://aistudio.google.com/)의 실제 할당량을 확인한다. 빠른 말이 오가는 대화에서 충분히 빠른지는 아직 미측정이다.

## 데이터와 대상

[공식 약관](https://ai.google.dev/gemini-api/terms)에 따라 무료 입력과 출력은 제품 개선 및 검토에 사용될 수 있다. 민감·기밀·개인 데이터는 제출하지 않는다. 성인 대상 및 지역별 이용 조건도 적용된다. EEA/영국/스위스 등 별도 조건은 실제 대상 지역에 맞춰 확인해야 한다. 이 프로토타입은 한국어 예선 시연을 전제로 하며 지역 차단은 구현하지 않았다.

무료 모드는 명시적 샘플 확인이 있어야 서버가 요청을 보낸다. 체크박스는 민감정보 자동 탐지·익명화 기능이 아니므로 실제 대화 데이터를 안전하게 바꾸어 주지 않는다.

원음과 문장은 앱 서버나 localStorage에 저장하지 않지만, 외부 제공사로 전송되어 그 정책에 따라 처리된다. 화면 종료/중단은 진행 중 요청을 취소하며 이미 전달된 데이터의 제공사 보관까지 소급 취소하지는 못한다.

## 전환 판단

| 시점 | 권장 |
|---|---|
| 예선 샘플 시연 | 무료 API + 자작 대화 + 할당량 확인 |
| 실제 대화 사용자 테스트 | 적합한 유료 데이터 처리 조건 + 동의 + 마이크/품질 검증 |
| 공개 상시 서비스 | 중앙 요청 제한·관측·예산 관리·지역/대상 통제 검토 |

## 설정

README의 5개 환경변수를 서버에 설정한다. Google 과금 계정이 무료이면 `GEMINI_DATA_MODE=free`를 유지한다. `paid`로 문자열을 바꾸는 것만으로 Google 데이터 정책이 바뀌지 않는다. API 키는 절대 NEXT_PUBLIC_ 변수로 만들지 않는다.
