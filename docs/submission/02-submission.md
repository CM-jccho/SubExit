# 제출 문안 · v0.3

## 프로젝트명과 한 줄 소개

**든든콜 — 내 상황을 기억하는 대화 코치.**

상대와 내 목표를 대화로 정리해 카드로 저장하고, 필요한 순간 그 맥락에 맞는 다음 한 문장을 준비합니다.

## 해결하려는 문제

어려운 대화는 상대의 말 한마디만으로 이해하기 어렵습니다. 누구와 어떤 관계인지, 내가 얻고 싶은 결과는 무엇인지, 어떤 약속은 피해야 하는지가 함께 필요합니다. 하지만 매번 이 배경을 설명하거나 정해진 시나리오를 골라야 하면 실제 상황을 담기 어렵습니다. 든든콜은 사용자 자신의 맥락을 저장하고 다시 꺼내 쓰는 흐름에 집중합니다. 수요와 실제 대화 개선 효과는 아직 검증해야 하는 가설입니다.

## 핵심 경험

1. '팀장님과 보고서 마감을 조율하고 싶어요'처럼 내 상황을 이야기합니다.
2. 상대·내 역할·상황·목표·지킬 선·말투로 정리된 카드를 확인하고 수정합니다.
3. 저장된 카드를 상대나 목표로 검색하고 다시 사용합니다.
4. 상대의 말을 적거나 최대 8초 들려주면, 저장한 맥락을 함께 참고해 다음 문장을 준비합니다.

홈의 XP와 고정 상황 선택을 제외했습니다. 문장 연습은 보조 기능입니다. 사용 횟수는 코칭 화면을 연 횟수이며 능력이나 성공률이 아닙니다.

## AI 역할과 구현 범위

Gemini 연결 시 자유 대화에서 카드 초안을 정리하고 중요한 누락 정보를 질문합니다. 사용자가 확인한 카드와 상대 발언으로 짧은 코칭 문장을 생성하며, 근거 인용이 실제 발언에 존재하는지 검사합니다. 짧은 음성 전사도 Gemini 경로를 사용합니다.

API 키가 없을 때는 질문 안내와 직접 입력으로 카드를 만들 수 있습니다. 이 기능을 AI로 표시하지 않습니다. 사전 작성 예시 역시 실제 AI 결과와 구분합니다. 무료 API 시연에는 개인정보·기밀 없는 자작 대화만 사용합니다.

카드 저장·수정·복사·검색·삭제·JSON 내보내기, 생성/수정/최근 사용일과 사용 횟수를 구현했습니다. 저장소는 이 기기의 브라우저이며 계정 동기화는 없습니다. 설정 대화 전문, 통화 원문, 음성은 카드에 저장하지 않습니다.

## 검증과 한계

자동 테스트 20개와 타입 검사, production build를 통과했습니다. 실제 키를 사용한 AI 초안·전사·코칭 품질, 지연, iPhone 마이크 호환성은 아직 검증하지 못했습니다. 모의 제공사 테스트는 실제 AI 품질 검증을 대신하지 않습니다.

현재 음성은 최대 8초 입력 후 처리하는 방식입니다. 대면이나 다른 기기의 스피커폰 옆에서 사용하며 같은 휴대폰의 통화 음성 직접 연동, 상시 스트리밍, 화자 분리는 지원하지 않습니다.

## 기술과 개발 도구

Next.js 15.5.25, React, TypeScript, Gemini generateContent API, MediaRecorder, 서버 Route Handler, localStorage.

ChatGPT Codex로 첨부 산출물과 코드 검토, 제품 구조 수정, UI 구현, 테스트, 제출 문안을 작성했습니다. Gemini는 앱 실행 시 카드 정리·음성 전사·코칭을 담당하는 연결 경로입니다. 기존 레포의 다른 개발 도구 이력은 작성자가 확인합니다.

## 30초 피치

“같은 말이라도 누구와 어떤 목표로 대화하느냐에 따라 답은 달라집니다. 든든콜은 상대와 내 목표, 꼭 지킬 선을 대화 카드로 저장합니다. 다음번에는 다시 설명하지 않고 카드를 꺼내 상대 말을 입력하면 됩니다. 우리는 많은 상황을 미리 정하는 대신, 사용자가 자기 맥락을 만들고 재사용하는 대화 코치에 집중했습니다.”
