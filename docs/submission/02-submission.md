# 제출 문안 초안

아래는 구현 범위에 맞춘 초안이다. 실제 API 검증·배포·대회 제출을 완료했다고 의미하지 않는다.

## 프로젝트명
든든콜

## 한 줄 소개
부담스러운 대화에서 상대 말을 바탕으로 내가 직접 말할 다음 한 문장을 제안하는 옆자리 코치.

## 해결하려는 문제
필요 없는 영업 전화나 무리한 부탁을 받으면, 하고 싶은 말이 있어도 즉석에서 정리하지 못할 수 있습니다. 통화가 끝난 뒤의 분석만으로는 '지금 뭐라고 답하지?'라는 순간의 필요를 채우기 어렵습니다. 든든콜은 영업 전화 수신자의 거절 상황을 첫 사례로 삼아, 그 순간 사용할 한 문장을 제안합니다. 문제의 빈도와 효과는 아직 사용자 조사로 검증하지 않은 가설입니다.

## AI 활용
대면이나 다른 기기의 스피커폰 옆에서 최대 8초의 짧은 음성을 받아 Gemini API로 전사합니다. 인식된 상대 말을 확인하면 대화 목적과 말투에 맞는 다음 한 문장을 생성합니다. 관찰 표현, 실제 인용, 대응 근거를 함께 제공하며 인용이 원문에 있는지 서버에서 검사합니다. 처리 중에는 마이크를 끕니다.

무료 API는 개인정보·기밀 없는 자작 샘플을 사용하는 시연 방식으로 설계했습니다. 실제 AI 결과와 사전 작성된 샘플 화면을 명확히 구분합니다.

## 구현 결과
지금 대화 코칭, 7개 상황의 직접 연습, 자기 점검과 고쳐 쓰기, 참여 XP, 복기 노트 내보내기를 구현했습니다. 마이크 시작·중단·시간 제한과 서버 오류 처리를 추가했습니다. 말해보카의 짧은 학습과 복습 흐름을 참고해 연습 화면을 구성하고, 홈에서는 실제 대화 보조를 먼저 선택하게 했습니다.

실제 키를 사용한 전사·코칭 품질과 전체 지연은 아직 측정하지 못했습니다. 코드 테스트와 프로덕션 빌드는 통과했으며, 실제 기기·시각 검증은 검증 기록의 남은 항목을 따릅니다.

## 기술 스택
Next.js 15.5.25, React, TypeScript, MediaRecorder, Gemini generateContent API, 서버 Route Handler, localStorage 참여 기록.

## 개발에 사용한 AI 도구
ChatGPT Codex로 첨부 문서·소스 대조, 제품 및 UI/UX 보강안, 구현, 테스트, 제출 문서를 작성했습니다. Gemini는 앱 실행 시 음성 전사와 코칭을 담당합니다. 기존 레포에서 사용한 다른 개발 도구 이력은 작성자가 확인 후 추가합니다.

## 30초 피치
“거절하고 싶은데 막상 전화를 받으면 말이 안 나올 때가 있습니다. 든든콜은 그 순간 상대 말을 바탕으로 내가 직접 말할 한 문장을 제안하는 옆자리 코치입니다. 짧게 듣고, 인식된 말을 확인하고, 내 목적에 맞는 멘트를 봅니다. 대화 전에는 같은 상황을 내 말로 연습하고 고쳐 쓸 수도 있습니다. 예선에서는 개인정보 없는 샘플 대화로 AI 연결을 보여주는 것을 목표로 합니다.”

실제 연결을 시연했다면 마지막 문장을 완료형으로 변경한다. 아직 하지 않은 시연을 했다고 기재하지 않는다.
