# 메신저 답장과 준비 중 기능

## 실제 제공 범위

홈 ‘카톡·메신저 답장 다듬기’ 또는 내 대화의 ‘메시지 답장’ 탭에서 시작한다.

1. 상대 메시지를 직접 붙여 넣는다. 관계·의도·전하고 싶은 것·지킬 선을 정한다.
2. ‘저장하고 답장 준비’로 입력을 이 브라우저에 저장한다.
3. 직접 답장을 쓰거나, AI 전송 안내 후 부드럽게·간결하게·단호하게 세 후보를 요청한다.
4. 후보 선택은 입력칸을 채우는 동작이며 자동 전송하거나 저장하지 않는다.
5. 답장을 수정해 복사하거나 저장한다. 복사는 클립보드에만 기록한다. 저장은 브라우저 대화 기록에 남긴다.
6. 저장한 기록을 다시 열어 수정·복사하거나 삭제할 수 있다.

업무 마감 조율·친구 부탁 거절·동료 검토 부탁의 작성된 가상 예시 3개를 제공한다. 예시와 AI 생성 결과의 출처를 기록과 화면에 유지한다. 예시는 현재 입력을 분석한 결과로 대체하지 않는다. 메신저 계정 연동·자동 전송·대화 자동 수집은 제공하지 않는다. 답장을 실제로 보냈는지도 추적하지 않는다.

## 저장·오류·전송

AI에는 선택한 상대 메시지·관계·의도·목표·지킬 선만 보내고 다른 대화 기록은 포함하지 않는다. 상대 메시지의 시스템 변경 명령은 신뢰하지 않는 인용문으로 취급한다. 없는 사실·일정·규정·약속을 만들지 않도록 지시하지만 결과의 의미 정확성을 보장하지는 않는다.

AI 요청 전에 입력을 저장한다. 한도·연결 실패 후 직접 답장을 작성하거나 별도 가상 예시를 볼 수 있다. 실패를 성공한 AI 후보로 저장하지 않는다. 화면 이탈 시 진행 중 요청을 취소하고 늦게 도착한 후보는 저장하지 않는다.

같은 입력의 후보 갱신은 같은 기록에 저장한다. 상대 메시지나 조건이 바뀌면 새 기록으로 저장해 이전 답장을 보존한다. 처음 입력과 최종 답장의 저장 시점을 구분한다. 복사 권한이 거부되면 텍스트를 선택하고 수동 복사 방법을 안내한다. 선택 후보나 저장 버튼만으로 외부 메시지는 전송하지 않는다.

일부 화면 내 이동·후보 교체와 새로고침/탭 종료에 미저장 확인을 둔다. 앱 전체 상위 메뉴 이동을 모두 보호하는 전역 초안 복구 기능은 여전히 별도 보완 대상이다. 데이터는 이 브라우저에 저장되며 기기 간 동기화되지 않는다. 현재 AI 운영 조건에서는 개인정보·기밀 없는 자작 연습을 사용한다.

## 준비 중 안내

실행 가능한 것처럼 보이는 버튼 대신 관련 화면의 ‘앞으로 추가될 기능’ 접이식 영역에 준비 중 배지를 둔다. 공개 일정은 정하지 않는다.

- 내 대화: 고민 정리
- 메시지 답장: 내보내기 파일·이미지에서 메시지 가져오기 확장
- 친구방: 실제 사용자 익명 커뮤니티, 독립적인 여러 에이전트의 실시간 대화
- 대화 기록: 긴 녹음·자동 화자 구분, 연속 실시간 음성 코칭
- 안내: 위 항목 전체 및 계정 동기화·전체 백업

현재 짧은 파일 분석·가상 라운지·생성된 대본 관찰 기능은 계속 제공한다. 새 준비 중 안내에서 현재 범위와 예정 범위를 구분한다.

## 검증

기존 111개에 새 9개 테스트를 추가해 120개 자동 테스트로 검증한다. API 입력 범위와 다른 기록 격리, 말투 계약, 후보 수정·복사·저장·재열기·삭제, 작성 샘플의 출처 보존, 한도 초과 후 직접 작성, 중복 없는 후보 저장, 변경 전 기록 보존, 복사 권한 거부, 이탈 후 늦은 응답 차단, 저장 실패, 준비 중 안내와 진입 경로를 포함한다.

제공자 응답과 클립보드는 자동 테스트에서 모의 처리한다. 실제 휴대폰 카카오톡 붙여넣기, OS별 클립보드 권한, 실제 AI 답장 품질은 별도 확인이 필요하다.
