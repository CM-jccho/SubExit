# 내가 준비할 대화부터 시작하기

문제: 불특정 다수의 샘플·역할·분야가 처음부터 함께 노출되어 자신의 시작점을 찾기 어려움.

변경:
- 첫 홈에서는 샘플 목록 전에 지금 필요한 대화 맥락을 선택한다: 직장 업무, 고객 응대, 학부모 상담, 친구와 가족. 고정 범주가 맞지 않으면 내 상황을 직접 설명한다. 전체 둘러보기도 가능하다.
- 선택은 별도 버전 키로 브라우저에 저장한다. 직업 추정·AI 호출·공개 프로필을 만들지 않는다.
- 선택에 맞는 홈/내 대화 샘플, 기본 AI 상대, 어려운 응대 예시, 용어 분야를 먼저 보여준다. 매칭은 명시적인 샘플 ID·분야 매핑이며 AI 추천이라고 주장하지 않는다.
- 개인 작성 카드는 맥락과 무관하게 유지한다. 사용자가 만든 캐릭터와 저장한 노트·기록도 삭제하지 않는다. 삭제한 샘플을 큐레이션 때문에 다시 생성하지 않는다.
- 전체 둘러보기는 일시적인 보기 변경이다. 기존 맥락 선택은 유지하며 내 선택만 보기로 돌아온다. 새로고침하면 저장한 선택을 기준으로 돌아온다.
- 첫 사용 튜토리얼은 샘플 맥락을 선택한 뒤 해당 상황으로 시작한다. 직접 상황 입력은 무관한 샘플 튜토리얼을 띄우지 않는다.
- 내 대화 상단은 둥근 실행 버튼에서 밑줄로 현재 위치를 나타내는 메뉴로 변경했다. 대화 연습 / 메시지 답장 / 기초 훈련 / AI 요청 연습과 현재 메뉴의 한 줄 설명을 제공한다.

검증:
- 자동 테스트 126개 통과: 선택 전 샘플 미노출, 맥락별 노출, 개인 카드 유지, 선택 저장/재진입, 전체 보기 왕복, 삭제 샘플 비복원, 추천 용어 분야/전체 분야 전환, 직접 상황 입력, 기존 튜토리얼·녹음·API·저장 흐름 포함.
- 프로덕션 빌드 및 타입 검증 후 PR에 저장한다.
- 새 화면의 실제 브라우저/휴대폰 시각 검증과 처음 사용하는 사람의 이해도 검증은 별도로 필요하다. 자동 테스트 통과만으로 실제 이해도 향상을 입증하지 않는다.

범위:
- 개인화는 우선 홈·내 대화·AI 대화 상대·분야별 용어에 적용했다. 훈련·메신저·일상 대화의 모든 개별 예시까지 재분류하는 작업은 포함하지 않았다.
- 공동 용어집은 포함하지 않았다. 기존 개인 노트 공개 범위를 유지한다.
