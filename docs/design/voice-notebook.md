# 음성 기록 · 역할 연습 · 우리 일의 말

2026-09-16

## 이번 변경

기존 ‘중단하기’가 녹음 종료와 인식을 하지 않고 녹음 결과를 버리는 취소 경로로 연결돼 있었다. 녹음 중에는 ‘녹음 끝내고 음성 인식’을 제공하고, 처리 중에는 별도 ‘처리 취소’를 제공한다. 종료 즉시 상태를 표시하며 인식 중·완료·실패를 구분한다. 임시 원본 재생과 재시도가 가능하다.

- 홈의 음성 기록 → 녹음/파일 → 실제 파형·재생 위치 이동 → 문자 인식 → 저장.
- 내 대화 카드 → 상대와 대화 연습 → 상대의 시작 발화 → 사용자 음성 또는 문자 → 상황에 맞는 AI 응답. 기기의 TTS로 상대 발화 읽기.
- 설정 질문에 2~3개 답변 후보와 자유 입력을 함께 제공. AI 후속 질문의 후보는 대화 맥락으로 생성한다.
- 역할 연습의 답변 후보 3개는 목표·지킬 선을 기준으로 생성. 후보를 선택해도 자동 전송하지 않는다. 입력칸에서 수정하거나 직접 녹음해 보내게 한다.
- 대화 단어 클릭·중요 용어 추출·표현 직접 스크랩 → 업종·뜻·예문·사용 맥락·팀 메모. AI 초안과 직접 확인을 구분한다.
- 선택한 용어의 공유 미리보기, 기기 공유 창, Markdown 가이드, 재사용 가능한 JSON 내보내기·가져오기. 음성과 대화 원문은 가이드에서 제외한다.
- 곁이의 듣기·생각·읽기·완료 상태 움직임과 상황별 한 문장 안내. 반복 성공 애니메이션은 짧게 마무리하고 reduced-motion에서는 정지한다.

## 범위와 데이터

기존 카드 저장 키는 변경하지 않는다. 새 음성·연습 기록과 용어는 별도 IndexedDB에 저장한다. 음성은 Blob 원본을 보존한다. 기록 쓰기가 완료된 후에만 저장 완료를 표시한다. 저장 실패 시 입력을 남겨 재시도할 수 있다. 서버에는 새 데이터베이스를 만들지 않는다.

녹음 최대 60초, 업로드 최대 120초·2.4MB. 긴 회의 전체 전사와 실시간 동시 통화는 이번 범위가 아니다. 기존 실제 대화 코칭은 8초 단위 입력을 유지한다. AI 연습 상대의 TTS 음성 파일은 보관하지 않으며 해당 문장을 저장해 다시 읽을 수 있다. 읽어주기의 음색·지원 언어·자동 재생은 기기에 따라 다르다.

실제 AI 입력은 기존 Gemini 전송·성인·샘플 모드 조건을 적용한다. API 키는 서버에만 둔다. 음성 MIME 별칭을 통일하고 크기 제한과 서버 입력 검증을 유지한다. 음성 인식 실패 시 녹음 원본은 UI에 남는다. 용어 설명은 모델의 초안이며 검색한 사전이나 검증된 정의로 표시하지 않는다. 영어·일본어·한국어 검색 링크를 제공하되 검색 결과를 읽었다고 표시하지 않는다.

공유는 앱 사용자가 선택한 내용으로 앱의 공유 UI를 통해 실행한다. 미리보기에 팀 메모가 포함됨을 표시한다. 가져오기는 검증된 JSON만 처리하며 같은 업종의 같은 용어는 기존 메모를 유지한다. 별도 계정·클라우드 동기화·공개 공유 URL은 제공하지 않는다.

## 검증

총 35개 테스트 통과 및 타입 검사·프로덕션 빌드 통과.

추가 테스트: 녹음 중 ‘끝내기’가 전사 요청으로 이어지는 UI 회귀, 원본 보존 및 재시도, 권한 거절 안내, 선택 후보가 자동 전송되지 않음, MIME 정규화, 역할·목표·대화 순서 전달, 잘못된 입력·AI 오류, 용어 원문 근거, 공유 범위, IndexedDB 음성·문자 저장과 삭제.

브라우저의 로컬 주소 접근은 차단됐다. 운영 반영 후 기능 확인 결과를 후속 기록한다. 실제 휴대폰 마이크 품질과 iOS·Android TTS 음색은 기기 시험이 필요하다.

## 확인한 공식 자료

- [Google Gemini Audio understanding (English)](https://ai.google.dev/gemini-api/docs/audio): 음성 입력으로 문자 출력을 만들 수 있는 API 구조.
- [MDN MediaRecorder (日本語)](https://developer.mozilla.org/ja/docs/Web/API/MediaRecorder): 녹음 데이터 및 stop 이벤트, 브라우저 API.
- [MDN SpeechSynthesis (日本語)](https://developer.mozilla.org/ja/docs/Web/API/SpeechSynthesis): 기기 음성 읽기와 재생 제어.

기존 배포의 gemini-2.5-flash 설정을 유지하며 모델 업그레이드를 이번 범위에 섞지 않는다.

## 운영 화면 확인

PR #29 운영 배포 이후 직접 만든 7초 영어 합성 음성으로 파일 업로드 → 실제 Gemini 전사 → 전체 원문 표시를 확인했다. 파형 재생 위치가 0초에서 7초까지 진행되었고 음성·문자를 저장한 뒤 새로고침해 기록 목록에 남는 것을 확인했다. 대화의 scope 단어를 눌러 Gemini 업종별 설명을 받고 팀 메모를 추가해 저장했으며, 선택한 용어의 공유 미리보기에 원문·음성 없이 뜻·예문·메모만 포함됨을 확인했다. 설정 후보 선택 시 입력칸만 채워지고 자동 전송되지 않음도 확인했다.

영어 용어 추출에서 원문 용어가 충분히 나오지 않은 사례를 발견해 원문 언어·철자·연속 표현 유지 지침을 강화했다. 다운로드 링크는 문서에 부착한 뒤 클릭하고 URL 해제를 늦춰 브라우저 호환성을 보완했다. 브라우저 자동화의 다운로드 이벤트 확인은 시간 초과가 발생해 파일 수신까지 확인한 것으로 기록하지 않는다.

역할 연습의 실측에서 상대가 사용자의 목표를 먼저 제안하고 후보 하나가 목표와 반대가 되는 사례를 확인했다. 상대 응답 요청에는 내 역할·상대·공유 상황·실제 대화만 전달하고, 사용자의 목표·지킬 선은 제외하도록 데이터 경계를 분리했다. 후보는 별도 요청에서 목표와 지킬 선을 받아 3가지 화법으로 생성한다. 이 경계를 검증하는 테스트를 추가하여 총 36개 테스트를 통과했다. AI 문장은 여전히 사용자가 확인하고 수정한 뒤 보내는 구조다.
