# 든든콜 — 첫 대화부터 이해되는 앱

## 핵심 구조

- 홈: 대화 준비하기 한 가지 주 행동, 다시 꺼낼 카드, 튜토리얼 재실행.
- 내 대화: 역할·목표로 찾기, 카드 수정·복사·삭제, JSON 내보내기. 기존 저장 키와 카드 스키마 유지.
- 대화 준비: 자유 대화 또는 네 가지 질문. 질문 안내에서는 한 번에 한 질문만 표시. 이전 대화는 펼쳐서 확인.
- 카드 확인: 요약을 먼저 보고 필요한 내용만 수정. 사용자가 저장한 카드만 재사용.
- 코칭: 전송 조건 확인 후 듣기·직접 입력 선택. 답변이 준비되면 모바일에서 문장을 먼저 표시.
- 사용 안내: 체험 다시 보기, 음성 사용 조건과 저장 위치, 연습 링크.

## 첫 실행 튜토리얼

첫 방문에서 캐릭터 ‘곁이’가 3단계 체험을 안내한다. 연습용 상황 카드 선택 → 상대 말풍선 선택 → 사전 작성된 답변 힌트 확인. 마지막에는 자신의 대화를 만들거나 홈으로 갈 수 있다. 선택 전에는 다음 버튼이 비활성화되며, 샘플은 명확히 표시한다. 실제 AI를 부르거나 카드를 자동 저장하지 않는다.

언제든 건너뛰기·Escape·닫기가 가능하다. 닫거나 완료하면 `ddeundeun-first-conversation-v1`에 표시해 반복을 줄인다. 저장이 차단되면 현재 체험은 닫히고, 다음 방문에 다시 나타날 수 있다. 안내 메뉴나 상단 도움말로 재실행할 수 있다. `?demo=1` 기존 바로가기 유지.

## 시각적 원칙

직접 제작한 경량 SVG 캐릭터, 종이색 배경, 짙은 녹색 행동 버튼, 손으로 그린 듯한 윤곽. 로봇·반짝임·가짜 대시보드 수치를 넣지 않는다. 캐릭터는 시작과 대기에서 안내하며 코칭 결과에서는 문장이 중심이다. 녹음 중에만 파형이 움직인다. 감소된 모션 환경에서는 애니메이션을 끈다.

긴 기술 설명은 필요한 위치의 펼침 도움말로 이동한다. 전송 동의, 무료 API 샘플 조건, 마이크 제약은 해당 행동 전에 표시한다. 대화가 성공했다는 점수나 보상을 만들어내지 않는다.

## 참고한 제품 원리

- 말해보카 공식: 짧은 과제와 친숙한 캐릭터를 통한 진입. https://epop.ai/
- Duolingo 공식 디자인 글(영문): 일관된 단순 도형과 캐릭터 표현. https://blog.duolingo.com/shape-language-duolingos-art-style/
- Speak 공식 일본어 페이지: 실제 행동에 집중한 대화·피드백 흐름. https://www.speak.com/jp/app

기존 제품의 캐릭터·색상·화면을 복제하지 않고, 든든콜의 ‘나의 상황 → 다음 한마디’ 흐름으로 적용했다.

## 검증 기준

기존 22개 API·저장 테스트, TypeScript, 프로덕션 빌드. 화면 점검에서는 첫 실행·건너뛰기·재시작, 단계 선택과 버튼 상태, 카드 생성·검색·수정·재사용, 390px에서의 가로 넘침과 하단 탐색, 도움말과 키보드 초점을 확인한다. 음성의 실제 통화 품질은 별도 기기 시험 범위다.

## 배포 후 확인 (2026-09-16)

운영 웹 브라우저에서 첫 진입 자동 안내, 3단계 선택과 버튼 활성화, 자신의 카드 만들기 연결, 네 가지 질문으로 새로운 상황 정리, 저장 도움말, 카드 저장, 새로고침 후 유지와 안내 비반복, 목표 단어 검색, 코칭 시작을 확인했다. Gemini 설정 활성도 유지됐다. `?tour=1`은 다시 보기 직접 링크다.

좁은 화면은 반응형 CSS로 구현했으나 이번 브라우저 환경에서 390px 렌더링을 검증하지 못했다. 실제 휴대폰 레이아웃·마이크 품질은 별도 기기 확인이 필요하다.

실제 Gemini 텍스트 코칭에서도 응답 생성과 결과·근거 펼침을 확인했다. 초기 응답이 일정 변경 목표를 문장에 포함하지 않는 사례를 발견해, 제안 문장 자체에 저장한 목표를 반영하고 근거 없는 세부사항을 추가하지 않도록 지침을 강화했다. 결과 패널에 내 목표를 함께 표시한다. 이는 모델의 모든 답변을 보장하는 결정적 검증은 아니다.
