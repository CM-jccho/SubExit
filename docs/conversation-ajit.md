# 대화 아지트

새싹 성장을 중심에 두던 보상을 장면 스탬프와 기록을 여는 기념품으로 바꾼다. 기존 보상 데이터는 같은 저장소에서 유지하며 잔액 명칭만 꾸미기 티켓으로 전환한다.

## 세 장면

| 장면 | 기념품 | 연습할 행동 |
|---|---|---|
| 부탁하기 | 마주 앉는 테이블 | 상대가 가능한 시간과 부탁 범위를 확인 |
| 거절하기 | 내가 지킬 선 메모보드 | 맡기 어려운 일을 말하고 가능한 대안을 제안 |
| 어려운 응대 | 잠깐 확인하는 카운터 벨 | 모르는 규정을 만들어 말하지 않고 확인·연결 방법을 안내 |

각 장면에는 가상의 AI 역할 연습 제안이 있다. 기본 연습은 티켓 없이 시작한다. 직접 두 번 답하기 → 실제 내 발언 한 문장 고쳐 저장하기 → 같은 장면에 다른 새 답변을 남기기를 원본 대화 하나에서 모두 마치면 스탬프와 기념품을 얻는다. 기념품은 소모되지 않는다.

기념품을 누르면 기록 팝업이 열린다. 원본 기록의 목표·지킬 선·현재 유효한 직접 복기 또는 AI 코칭 문장을 보여준다. 복기 기록 열기, 같은 맥락으로 재연습 생성, 완료했던 재연습 기록 보기를 지원한다. 연결된 기록을 삭제했으면 없는 이유를 표시하고 기록을 재생성하지 않는다. 스탬프는 남는다. 문장 수정 이력을 별도 스냅샷으로 저장하는 기능은 아니므로 ‘기록에 저장한 문장’으로 표시한다.

완료 후에는 상대가 한 번 더 거절하거나 답을 재촉하는 등 작성된 추가 조건을 제안한다. 기본 목표와 지킬 선을 유지한 새 연습이며, AI가 개인 평가로 생성한 다음 퀘스트로 표현하지 않는다.

## 보상 유지

- 기존 물방울의 누적·사용·잔액, 화분·머그컵·별빛 장식의 소유·배치는 그대로 유지한다. 새싹 성장 표시는 제거한다.
- 티켓은 기존과 동일하게 +2/+1/+3, 소품 교환은 2장. 샘플 보기·답변 후보 그대로 전송·복사된 이전 발화는 제외한다.
- 기존 기록에 세 단계 완료의 원장이 있고 해당 장면 템플릿이 정확히 일치할 때만 스탬프를 보충한다. 이 과정에서 티켓을 지급하지 않는다. 임의의 개인 대화에 업종이나 상황 분류를 추측해 부여하지 않는다.
- 변경·마이그레이션은 IndexedDB 트랜잭션으로 처리한다. 기기 간 동기화·실제 결제·현금 가치는 제공하지 않는다.

## 검증 범위

장면별 완료와 원본 연결, 세 단계가 다른 대화로 흩어진 경우 제외, 기존 보상 보존·반복 마이그레이션, 삭제된 기록 미복원, 추가 조건의 목표·지킬 선 보존을 테스트한다. UI 회귀 검사는 기념품 팝업에서 복기 열기·재연습 생성·원본 삭제 안내를 포함한다. 모바일은 한 열 배치와 44px 이상의 주요 버튼을 적용한다. 실제 휴대폰 렌더링·음성 품질은 별도 확인이 필요하다.
