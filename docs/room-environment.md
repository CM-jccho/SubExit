# 친구방 카드와 시간·날씨

## 제공하는 동작

- 친구 선택 즉시 네이티브 모달 카드가 열린다. 데스크톱은 중앙, 작은 화면은 아래에서 올라오는 카드다. 캐릭터·이름·전문 분야·대화 시작 버튼은 상단에 남고, 긴 기록만 내부에서 스크롤한다.
- 이전/다음 친구, 최근 3개 대화, 이전 기록 펼치기, 설정 변경을 지원한다. 닫기·Escape·배경 클릭으로 닫으며 선택한 친구로 키보드 초점을 돌려준다.
- 친구의 가벼운 이동, 식물과 구름, 비·눈 움직임을 CSS로 표현한다. 클릭 대상 자체는 고정되어 움직이는 캐릭터도 누르기 쉽다.
- 창문·벽시계·선반·책·머그컵·조명·화분이 있는 방에 아침/오후/해 질 녘/밤 색상과 빛을 적용한다.

## 실제 시간과 날씨의 범위

- 시간은 한국 시간(Asia/Seoul) 기준으로 30초마다 갱신한다. 아침 06–12시, 오후 12–17시, 해 질 녘 17–19시, 밤 19–06시다. 실제 천문학적 일출·일몰이나 달의 위상 계산은 하지 않는다.
- 기본 지역은 서울이며 인천·부산·대구·대전·광주·강릉·제주로 바꿀 수 있다. 기기 위치 권한은 요청하지 않는다. 선택한 도시 중심 좌표를 사용하므로 사용자의 정확한 위치 날씨라는 뜻이 아니다.
- `/api/room-weather`가 Open-Meteo의 현재 모델 날씨(기온, WMO 날씨 코드)를 받는다. 화면에 도시, 기준 시각, 데이터 출처를 표시한다. 관측소 실측값으로 표현하지 않는다.
- 허용된 도시만 조회하고 서버 7초·화면 12초 제한을 둔다. 서버 데이터는 30분, 응답은 5분 캐시한다. 방이 보일 때 30분 간격/탭 재진입 시 갱신한다. Gemini 호출은 사용하지 않는다.
- 잘못된 값, 90분보다 오래된 값, 10분 이상 미래 값은 표시하지 않는다. 실패하면 ‘날씨 연결이 잠시 어려워요’와 시간만 반영한다는 안내를 표시한다.
- ‘방 설정 → 방 분위기’의 미리보기는 실제 현재 시간을 바꾸지 않는다. 방에 미리보기 표시가 남으며 재진입하면 현재 시간으로 돌아온다.
- 도시와 움직임 설정은 이 브라우저에 저장한다. 운영체제의 움직임 줄이기도 존중한다. 이 기능은 기존 대화·음성·캐릭터 저장 데이터를 변경하지 않는다.

## 확인 및 남은 검증

- 자동 검증: 카드 즉시 표시/친구 전환/기록 연결/초점 복귀/편집 취소, 날씨 실패 안내, 움직임 설정 저장, 한국 시간 경계, 날씨 데이터 검증, 허용 도시와 오류 응답.
- 운영 브라우저 확인: 팝업의 캐릭터·대화 버튼·기록이 스크롤 없이 보임, 친구 전환, 편집 취소 후 카드 복귀, Escape 닫기와 초점 복귀. 서울·부산의 현재 날씨 수신, 밤 미리보기, 움직임 끄기도 확인했다.
- 실제 휴대폰 렌더링과 기기별 성능은 별도 확인이 필요하다.
- 브라우저 검증에서 장식의 넘침 때문에 방 내부가 24px 밀리는 현상을 발견했다. 방의 overflow를 clip으로 바꿔 초점 이동 시 내부 스크롤을 방지하고, 밤의 바닥 무늬 대비도 낮췄다.
