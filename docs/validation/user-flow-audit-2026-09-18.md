# 스픽코칭 사용 흐름 검증 — 2026-09-18 한국 시간

## 판정과 범위

실제 운영 브라우저에서 기능을 순서대로 눌러 입력·저장·다음 행동·복귀를 확인했다. 자동화 테스트 통과를 전체 서비스 품질이나 모바일 실기기 검증으로 해석하지 않는다.

- 브라우저: 데스크톱 화면 직접 조작. 모바일 화면 및 실물 마이크·키보드는 이번에 검증하지 않았다.
- 사용 데이터: 검증자가 직접 작성한 가상 약속 조정 문장과 서비스 내 사전 작성 예시. 사용자 음성 파일은 전송하지 않았다.

**제출 준비 완료 판정은 보류한다.** 샘플·텍스트 기록 흐름은 확인했지만, 실제 AI 정상 응답과 모바일 실기기 음성·키보드가 남아 있다.

## 발견하여 수정한 문제

1. **샘플 진입이 AI 동의 뒤에 숨음:** 실시간 도움의 시작 전 화면에 ‘이 상황을 샘플로 체험하기’를 추가했다. 연결과 동의가 없어도 선택한 상황 그대로 직접 입력 체험 가능. AI로 바꿀 때는 동의 검사를 유지한다.
2. **대화 재열기 시 샘플 선택 소실:** 사용자가 선택한 샘플 모드를 기록에 저장하고 재열 때 복원한다. 이 값은 AI 전송 동의가 아니며 동의를 저장하지 않는다. 설정 저장 완료 때문에 이미 떠난 화면으로 되돌아오지 않도록 처리했다.
3. **스크랩을 찾으러 갔는데 예시 목록이 먼저 표시됨:** 관심 분야가 선택되어 있어도 용어 노트는 ‘내 노트’부터 열리게 했다. 분야별 표현은 별도 탭에서 계속 사용할 수 있다.
4. **현재 동작과 다른 안내:** ‘8초 녹음’, ‘2분·2.4MB’ 등의 오래된 도움말을 현재 코드의 연속 듣기 지원/4초 녹음 대안/30분·50MB 가져오기에 맞췄다. 샘플·직접 입력 화면에서 마이크를 누르라는 안내도 고쳤다.

- 기존 검사에는 입력 실패·재시도·429·취소·중복 전송·저장 실패·모바일 조건 분기 등이 포함되지만, 가짜 응답/녹음기/JSDOM 기반 검사는 실제 Gemini나 iPhone 동작의 증거가 아니다.

## 남은 제출 전 확인

- 실제 용어 찾기는 이번 요청에서도 일일 한도 초과를 반환했다. 한도 복구를 확인한 뒤 실제 용어 추출·음성 전사·코칭 정상 성공을 확인해야 한다.
- iPhone Safari 및 카카오 인앱, Android Chrome에서 마이크 허용/거절, 녹음 재생, 키보드 열린 상태의 입력·닫기·하단 버튼, 백그라운드 복귀를 실제 기기로 확인해야 한다.
- 온보딩 손가락 스와이프, 긴 음성 파일의 전체 처리, 외부 앱 공유는 이번 운영 브라우저 점검에서 완료하지 않았다.
- 이 보고서는 모든 페이지·모든 조합이 통과했다는 의미가 아니다. 확인한 경로와 남은 경로를 구분한 결과다.

## 수정 반영 후 사용자 흐름 재확인

- 새로고침하고 용어 노트에 재진입: ‘내 노트’ 선택과 직접 저장한 표현 확인.
- AI 동의가 없는 상태에서 친구 상황 → ‘이 상황을 샘플로 체험하기’ → 상대 말 입력 → 힌트 표시 성공. 친구에게 사과하고 시간을 함께 조율하는 문장이며 사전 작성 샘플 표시 유지. 데스크톱 결과 화면도 시각 확인.
- 저장된 친구 연습에서 샘플 모드 선택 → 내 기록으로 복귀 → 같은 기록 재열기: 샘플 체크와 3개 말풍선 유지 확인.

## 로고·용어 노트 개선 후 추가 검증

- 헤더와 온보딩에 새 말풍선 로고를 적용하고, 파비콘과 홈 화면 아이콘을 연결했다. 운영 화면에서 헤더 이미지 로드와 아이콘 링크를 확인했다.
- 용어의 뜻·사용 예·사용 주의는 읽기 상태로 표시하고 눌러 수정한다. 개인 메모는 선택 항목으로 접어두며 기존 내용은 유지한다.
- 저장 완료 안내가 ‘내 노트’ 탭 안에만 있었던 문제를 수정했다. 분야별 표현·소통 팁에서도 저장한 표현명과 ‘내 노트에서 보기’를 표시한다.
- 실제 운영 데스크톱 브라우저에서 분야별 표현 → ‘핫픽스’ → 메모 없이 추가 → 완료 안내 표시·포커스 → 내 노트에서 보기 → 저장한 항목 재열기 → 선택 메모 입력·완료 → 변경 저장 → 목록에 메모 유지까지 확인했다. 저장 중 안내와 버튼 비활성화도 확인했다.
- 전체 자동화 검사 **190개 통과, 실패 0개**, 프로덕션 빌드 성공. 새 검사는 탭을 유지한 저장 완료 안내·다음 행동, 중복 클릭 방지, 저장 실패 시 초안 보존과 재시도를 포함한다. 기존 소통 팁 검사로 메모 재열기와 중복 없는 수정을 확인했다.
- 이번 추가 검증 역시 실물 모바일 키보드·음성 및 실제 Gemini 정상 응답 검증을 대신하지 않는다. 제출 준비 완료 판정은 위 미확인 항목 때문에 보류한다.
