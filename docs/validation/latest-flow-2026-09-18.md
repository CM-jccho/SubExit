점검일: 2026-09-18. 운영: https://speakcoaching-one.vercel.app/

## 판정

운영의 paid 설정과 실제 Gemini 호출은 정상입니다. 자동 테스트 및 빌드는 통과했습니다. 브라우저 직접 연결이 실패하여 화면 클릭을 통한 실제 종단 간 검증, 모바일 배치와 마이크 실기 검증까지 완료한 상태는 아닙니다.

## 배포·설정 근거

- 점검 시작 시 운영 커밋: dfadf796dd2ca5177eb3a8729732d7dfdeaf9310.
- 저장소 main과 운영 배포 커밋 일치. 로컬/원격 소스 트리: 05733c86697bc2c6de8f3dfe6122750404438452.
- 운영 /api/coach: HTTP 200, available=true, voiceAvailable=true, sampleOnly=false, model=gemini-2.5-flash.
- 이는 앱의 GEMINI_DATA_MODE=paid 반영을 확인한 것입니다. Google 결제 등급, 잔액, 15,000원 예산 상한은 결제 화면에 접근하지 못하여 별도로 확인하지 못했습니다.
- 아래 AI 요청은 모두 가상의 검증용 대화이며, sampleConsent=false로 호출했습니다. 실제 사용자 기록은 사용하지 않았습니다.

## 발견하여 보강한 경로

이전 일일 한도 오류가 sessionStorage에 남으면 유료 전환 뒤에도 해당 브라우저에서 요청이 로컬 차단될 수 있었습니다. 한도 안내의 ‘지금 사용할 수 있는 기능’ 안에 ‘이용 재개 후 다시 시도’를 추가했습니다.

- 이전 로컬 대기 상태만 해제합니다. 입력·기록·동의는 그대로 둡니다.
- 복구 버튼 자체로 AI 요청을 보내지 않습니다. 원래 요청 버튼을 다시 눌러야 합니다.
- 실제 한도가 남아 있으면 제공자 응답에 따라 다시 제한합니다. 예산/서버 제한을 우회하지 않습니다.
- 회귀 테스트로 이전 대기 차단, 명시적 해제, 입력 보존, 자동 요청 없음, 실제 제한 재적용을 확인했습니다.

## 사람이 마지막으로 확인할 시뮬레이션

1. **PC Chrome**: 새로고침 → 답변 코칭 → 직접 입력에 ‘돈을 빌려줄 수 있어?’ → 목표 ‘정중하게 거절하기’ → 동의 → 요청. 거절 의도와 결과가 맞는지 확인합니다.
2. **탭 왕복**: 직접 입력 → 들려주기 → 실시간 자막 → 직접 입력. 세 탭 위치·순서가 같고 입력과 목표가 남는지 확인합니다.
3. **실제 음성**: 실시간 자막에서 별도 음성 전송 동의 → 듣기 시작 → ‘약속 시간을 바꿀 수 있을까?’ 발화. 자막과 AI 코칭을 각각 확인하고, 듣기 멈춤 후 추가 인식이 없는지 확인합니다.
4. **모바일 Safari**: 360~390px 폭에서 홈/코칭/연습 준비/도움말을 열고 스크롤·키보드·닫기·하단 버튼을 확인합니다. 실시간 자막 미지원이라면 이유 안내와 다른 입력 방법이 보여야 합니다.
5. **연습→기록**: 상황 선택 → 대화 2회 → 복기 → 내 기록 → 재열기 → 같은 장면 연습. 내용·목표·복귀 위치를 확인합니다.
6. **녹음→용어**: 홈의 내 대화 돌아보기 → 10초 녹음 또는 파일 추가 → 문자 확인 → 화자 지정 → 코칭. ‘API, 핫픽스’가 포함된 문자에서 용어 찾기 → 뜻 설명 → 내 노트 저장 → 저장 확인과 재열기를 확인합니다.
7. **기존 한도 안내 사용자**: ‘지금 사용할 수 있는 기능’ → ‘이용 재개 후 다시 시도’ → 원래 요청 버튼. 기존 입력 보존 및 새 실제 응답을 확인합니다.

검증용 브라우저는 CDP 탭 연결이 두 번 시간 초과하여 실기 검증을 중단했습니다. 이 제한을 해소하기 전에는 ‘모든 환경에서 이상 없음’으로 제출 상태를 단정하지 않습니다.
