## 결론

**요청한 주요 흐름은 상당 부분 구현됐지만, 모든 요청이 적용·검증 완료된 상태는 아니다.** 핵심 구조는 ‘대화 연습 → 실제 발화에 근거한 복기 → 같은 장면 재연습’으로 유지된다. 저장·복사·녹음 오류 안내와 입력 팝업 보완은 코드에 있고 Render의 배포 자산에서도 확인했다.

실제 AI 코칭 성공, 휴대폰 마이크·클립보드·키보드, 화면 깜빡임 해결은 검증 완료로 처리할 수 없다. 공동 용어 사전, 계정 동기화, 연속 실시간 음성 코칭, 실제 익명 커뮤니티, 독립적인 여러 에이전트 대화는 아직 없다. 일부는 의도적으로 샘플 또는 검토 중 항목이다.

이 문서의 ‘자동 검증’은 단위·API 계약·JSDOM 컴포넌트 통합 테스트를 뜻한다. 실제 브라우저에서 사람이 클릭한 검증과 다르다.

## 5. 용어·세대·언어·훈련

29. **용어 스크랩·뜻·메모·가이드 공유 — 구현·자동 검증.** 대화에서 표현을 선택하거나 직접 추가하고 AI 뜻풀이 초안을 편집·저장한다. 공유는 선택한 노트의 파일/공유 창 전달이다. 기본은 나만 보는 노트다.
30. **다른 사람이 용어 정의를 더하기 — 미구현.** 현재 단일 뜻과 메모를 개인적으로 수정하는 기능이다. 여러 작성자의 정의 누적, 투표, 변경 이력, 공개 용어 사전, 공동 편집은 없다. 요청 전체가 반영됐다고 말할 수 없는 부분이다.
31. **업종·10대·실제 응대 예시 다양화 — 구현.** IT·기획·마케팅·유통·물류·재무·교육·고객 응대·학교생활·게임·영어·일본어 등 17개 용어 그룹. 부탁하기, 상담 시간 정하기, 무리한 환불 요구, 폭언에서 선 긋기 샘플과 응대 페르소나가 있다. ‘10대 전체가 사용하는 최신 유행어’로 단정하지 않도록 온라인·일상 표현으로 안내한다.
32. **지금 유행하는 용어 검색 — 연결 코드·계약 테스트 구현, 실검색 품질 미검증.** 공개 표현만 Gemini Google Search로 찾아 검색일·출처를 함께 보여주며 근거가 없으면 목록을 추측하지 않는다. 최신 인기 순위를 측정하는 기능은 아니다. 이번에는 한도 문제로 실제 검색을 실행하지 않았다.
33. **언어 설정 — 한국어·영어·일본어 부분 지원.** 내 언어와 상대 출력 언어를 별도로 전달한다. 전체 UI 번역, 모든 기능의 모든 언어 조합, 언어별 음성 인식·발음 품질은 검증하지 않았다.
34. **의사소통 꿀팁 — 구현·자동 검증.** 전후 표현과 설명을 보고 내 노트에 담아 메모할 수 있다. 사용자 참여형 공개 콘텐츠 CMS가 아니다.
35. **영역별 대화 근력 훈련 — 구현·자동 검증.** 생각 넓히기, 질문 이어가기, 핵심 전달의 세 영역. 답변·점검·수정·저장 후 기존 장면 재연습으로 돌아간다. 대화력의 객관적 점수나 효과 측정은 없다.
36. **일상 루틴·스몰토크 — 수동 실행 기능 구현·자동 검증.** 시간대와 관심 주제에 맞는 짧은 대화, 저장·재열기, 한도 시 사전 작성 응답을 지원한다. 매일 아침 자동 알림·예약 시작 기능은 없다.
37. **프롬프팅 — 제한된 과제 연습 구현·자동 검증.** 회의록 정리, 고객 응대문 작성, 제안서 초안 요청의 조건 선택·실행·결과 확인·버전 저장. 최신 기법을 지속 검색·업데이트하는 강의나 범용 에이전트 설계 도구는 아니다.
38. **결정할 때 상담·고민 정리 — 미구현.** 사용 안내의 검토 중 항목이며 전용 선택지·판단 기준·결정 기록 흐름은 없다. AI 자유 대화가 전용 상담 기능 구현을 뜻하지 않는다.

## 6. 데이터·동의·장애 대응·제출

39. **데이터가 계속 남는가 — 저장 완료된 항목만 해당 주소·브라우저에 유지.** localStorage/IndexedDB 저장, 실패 안내, 삭제·재열기 테스트가 있다. 팝업을 닫은 미저장 초안은 같은 화면 안의 임시 상태이며 영구 저장이 아니다. 브라우저 정리·시크릿 모드·저장 공간 정책으로 삭제될 수 있다. 새 Render 주소에는 Vercel 기록이 자동으로 따라오지 않는다.
40. **처음부터 샘플 유지 — 구현·자동 검증.** 최초 샘플과 추가 버전 샘플을 넣고, 삭제한 샘플은 반복 실행으로 부활시키지 않는다. 필요한 경우 수동 복원한다. 새 주소는 저장소가 달라 최초 샘플이 다시 보일 수 있다.
41. **동의가 너무 많음 — 부분 개선.** `AIConsent`로 공통 문구를 사용하고 동의 후 접는다. 내용 확인·철회가 가능하다. 기능별 상태가 분리돼 화면 이동·재진입 시 다시 동의할 수 있으며 앱 전체에서 한 번만 확인하는 체계는 아니다. 법적으로 매번 필수인지 이번 기술 점검으로 판단하지 않는다.
42. **한도·오류 시 다양한 샘플 — 구현·자동 검증.** 준비된 응답 묶음, 반복 회피, 오류 종류·재시도 시각·샘플 출처 저장과 재열기를 테스트했다. `ai-outage-simulation.json`이 있다. 전사·실제 복기는 가짜 분석으로 대체하지 않는다. 근거 인용 오류를 단순 연결 장애와 동일하게 숨기지 않는다.
43. **호스팅 이전 — 새 Render 사이트 응답 확인.** Gemini 키 설정과 샘플은 작동한다. 실제 AI 요청 성공은 미확인이다. 개인 기록 자동 이전은 미구현. Render 계정 연결이 없어 제공사 대시보드의 정확한 배포 커밋·요금제·로그는 직접 확인하지 못했다.
44. **해커톤 산출물 — 문안·고지는 있으나 최종 제출 완료 아님.** 최종 문안·AI 도구 표기·라이선스 고지는 존재한다. 최신 화면을 검증한 대표 이미지/최대 5장 16:9 스크린샷, 참가 자격·제작 권리·회사 규정 확인, 필수 입력과 최종 제출 버튼 완료, 심사 기간 접속 유지가 남는다. 이번 소스에서 확인한 범위를 넘어서 다른 저장 위치의 산출물까지 없다고 단정하지 않는다.

## 발견 사항과 이번 조치

- **README의 주제·저장 정책·보상 설명이 오래됨:** 카드 저장과 예전 XP, 음성을 저장하지 않는다는 문구가 현재 사용자 기록과 맞지 않았다. 현재 연습·복기·재연습, IndexedDB 음성 저장, 티켓/장면 스탬프, Render 안내로 수정했다.
- **최종 제출 문안의 주소·검증 수·배포 상태가 오래됨:** Render 주소, 139개 자동 테스트, 현재 AI 실패와 남은 확인을 반영했다. 과거 버전으로 표시된 문서는 역사 기록으로 유지했다.
- **최신 코드의 화면 포함 여부:** 운영 자산에서 관련 문구·CSS를 확인했다. 클릭 동작·시각적 완성도까지 검증됐다고 확대하지 않는다.
- **실제 AI 코칭 500/429:** 발견 사항으로 남겼다. 인용 검증을 완화해 잘못된 근거를 통과시키지 않았다. 할당량 회복 후 가상 입력으로 재현하고, 실제 모델 출력을 토대로 프롬프트·응답 계약의 보완 지점을 확인해야 한다.

이번 변경은 보고·README·제출 문안이다. 새 UI 또는 API 수정이나 자동 재배포를 수행한 것이 아니다.

## 남은 테스트의 우선순위

### 제출 전 필수

1. **실제 AI 핵심 흐름 1회:** 가상 부탁 상황 → 직접 두 번 답변 → 복기 → 실제 인용 확인 → 문장 수정 → 같은 장면 재연습. 오류 코드·응답 시간·인용을 기록한다. 일일 한도 상태에서는 중단하고 반복 호출하지 않는다.
2. **iPhone Safari와 Android Chrome:** 녹음 권한 허용/거부 → 10초 녹음 → 중지 → 재생·문자 변환 → 저장 → 새로고침 후 유지. 외부 파일은 제한 안의 실제 파일로 수정·화자 확인·분석까지 진행한다.
3. **답장 복사·저장:** 답장 편집 → 복사 → 메모 앱에 붙여넣어 일치 확인 → 저장 → 새로고침 → 재열기·수정 → 기록 중복 없음 확인. 실패 안내가 버튼 옆에 보이는지 확인한다.
4. **입력 팝업·깜빡임:** 한글 조합, 키보드 열기/닫기, 팝업 닫기·이어쓰기, 느린 응답 중 저장, 내부 메뉴·뒤로 가기·새로고침의 미저장 취소/승인 확인. 실제 영상으로 위치 이동 여부를 비교한다.
5. **제출 자료:** 실제 위 핵심 흐름을 보여주는 화면을 캡처하고, 서비스 링크를 Render로 입력한다. 샘플 화면은 샘플로 표시한다. 실제 심사 접속은 현재 무료 요금제의 대기·한도 영향을 확인해야 한다.

### 제품 완성도 개선 판단

우선 권고는 기능을 더 늘리는 것보다 1~4번의 실패 가능성을 줄이는 것이다. 공동 용어 정의는 새로운 서버 저장소·작성자/공개 범위·이력 정책이 필요한 별도 범위다. 커뮤니티·연속 음성·의사결정 상담 확장은 핵심 흐름을 실제로 검증한 뒤 선택하는 편이 현재 해커톤 주제를 더 명료하게 유지한다.

주제 희석 위험은 남아 있다. AI 요청 연습·일상 대화·방·커뮤니티가 모두 핵심처럼 소개되면 ‘무슨 앱인가’가 다시 흐려질 수 있다. 제품 소개와 시연은 부탁·거절 한 장면의 연습 전후에 집중하고 보조 기능은 더보기에서 필요할 때 찾는 현재 방향을 유지하는 것을 권고한다. 이는 기획 판단이며 효과가 측정된 결론은 아니다.
