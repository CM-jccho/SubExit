# 웹 사용성 검증 — 2026-09-18

## 범위와 결론
데스크톱 Chrome 클라우드 브라우저(1363 × 936)에서 실제 공개 사이트를 조작했다. 이번 점검은 웹 사용 흐름이며, 실물 모바일·Safari·Firefox·실제 마이크 녹음 검증을 대신하지 않는다.

확인한 샘플 대화·기록·스크랩 경로는 진행할 수 있었다. 세 가지 사용성 문제를 재현하고 수정해 배포했다. 실제 AI 성공 응답은 일일 한도로 확인하지 못했으므로 전체 기능 통과 또는 최종 제출 준비 완료로 판단하지 않는다.

| 작성 중 홈으로 이동할 때 초안 손실 위험 | 미완성 상황·답변·설정 변경이 있으면 화면 이탈 및 새로고침 보호. 저장 후에는 경고 해제 | 자동 테스트로 취소 보존·수락 이동·저장 후 해제 확인. 실제 화면 이탈 시 기본 확인창 발생은 확인했으나 자동화가 멈춰 수락·취소 클릭은 미완료 |
| 저장 버튼이 비활성인데 빠진 항목을 파악하기 어려움 | 저장 위에 필요한 필수 항목을 구체적으로 표시 | 배포 화면과 자동 테스트에서 확인 |

## 실제 브라우저에서 진행한 흐름
- 온보딩: 다음 두 번 → 마지막의 ‘내 대화 시작하기’ → 홈.
- 대화 연습: 친구 약속 조정 샘플 → 시작 → 상황에 맞는 답변 후보 세 개 확인 → 첫 후보 클릭 한 번으로 전송.
- 전송 결과: 상대·나·상대 세 메시지 표시, 전송한 문장 일치, 다음 상대 답변으로 포커스 이동. 가로 넘침 없음.
- 기록 복귀: 내 기록에서 해당 대화를 다시 열어 전송 문장과 세 메시지 유지 확인.
- 문자 기록: 가상 대화를 직접 입력 → 입력창 닫기 → 이어쓰기에서 같은 내용 유지 → 저장 → 저장 안내와 다음 행동 표시.
- 표현 저장: 직접 스크랩 → 표현 입력 → 바로 저장 → 처리 중 중복 클릭 방지 → 창 닫힘과 저장 안내 확인. 이번에 저장한 항목을 노트 목록에서 재조회하는 단계는 수행하지 않음.
- 용어 찾기: 동의 전 안내와 비활성 시작 버튼 → 동의 후 시작 가능 → 실제 요청 → 일일 한도 오류 및 직접 스크랩 대안 표시. 원문 유지 확인.
- 배포 후 재확인: 주 주소에서 필수 항목 안내, 편집 시작 포커스, 완료 후 요약 버튼 포커스 확인.

검증에는 가상의 약속 조정 문장만 사용했다. 실제 음성 전송은 수행하지 않았다.
