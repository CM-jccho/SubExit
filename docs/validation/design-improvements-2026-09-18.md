## 그대로 복사하지 않은 제안과 이유

- 홈의 큰 3칸 순서 카드: 사용자가 앞서 요청한 한 줄 순서 안내를 유지했습니다.
- 온보딩 다음 버튼을 시작하기와 같은 솔리드로 통일: 두 버튼을 구분해 달라는 기존 요청을 유지했습니다.
- ‘Chrome에서 바로 사용 가능’: API 존재만으로 실제 권한·음성 서비스 연결을 보장하지 않으므로 기능 감지와 조건부 안내를 사용했습니다.
- 별도 scrim·포커스 트랩 중복 추가: 현재 입력창은 이미 native dialog.showModal을 사용합니다. 기존 backdrop과 포커스 처리를 유지하고 footer 배치를 보강했습니다.
- 동의의 데이터 사용 조건까지 접기: 무료 API 입력의 이용 조건은 동의 전에 볼 수 있게 남겼습니다.
- 새로운 가로 캐러셀/화면 스와이프: 온보딩 외 스와이프를 빼 달라는 요청에 따라 추가하지 않았습니다. 예시는 일반 목록으로 표시합니다.
- 모든 링크에 무조건 44px 강제: 문장 중 인라인 링크까지 블록처럼 커지지 않도록 동작 버튼과 요약·라벨 중심으로 적용했습니다.
- 고정된 폭의 전체 입력창 축소: 텍스트 입력의 읽기·수정 영역은 확보하고 데스크톱 주요 행동 버튼의 너비를 제한했습니다.
- 모든 아바타 강제 교체: 기존 상황·동반자 선택에 따른 캐릭터를 유지했습니다. 기존 캐릭터 선택을 장식 목적의 임의 이미지로 덮어쓰지 않았습니다.

## 검증

- 자동 테스트: **194개 통과, 실패 0개**.
- 프로덕션 빌드: 성공, 빌드 내 타입 검사 통과.
- 확인한 동작: 기록 필터·정렬·검색 조합, 브라우저 음성 API 감지 안내, 작은 목록 검색 생략, 준비 화면 복귀, 미저장 입력 이동 취소, 설정 모달에서 샘플 상태 변경·저장, 모달 footer 저장 버튼, 초안 보존·중복 저장 방지.
- 테스트는 jsdom·모의 API·저장소 등을 포함합니다. 194개 실제 기기 E2E가 아닙니다.
- 색상 조합 계산: 본문 #293d35 / 카드 #fffefa = 11.48:1, 보조 #4a5f52 / 카드 = 6.82:1, 보조 / 내 말풍선 #dbe9c9 = 5.41:1, 주요 버튼 글자 #fffefa / #2f5d3a = 7.57:1.
- 이번 브라우저 연결 확인은 CDP refresh timeout으로 실패했습니다. 배포 후 실제 모바일·데스크톱 레이아웃, 줄바꿈·잘림, iOS 키보드·마이크, 실제 화면의 전체 대비·터치 타깃 재계측은 완료하지 못했습니다.
- Gemini API 코드는 이번 디자인 수정에서 바꾸지 않았습니다. 직전 검증의 코칭 1건 성공/용어 추출 일일 한도 429 상태와 구분해야 합니다. 불필요한 실제 AI 재호출은 하지 않았습니다.
