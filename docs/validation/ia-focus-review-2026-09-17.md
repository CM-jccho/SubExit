## 수정 결과

- 홈은 지금 대화 도움받기 주 버튼과 미리 연습하기 보조 버튼. 상황을 선택한 진입 목적을 URL에 유지해 각각 실전 코칭과 역할 연습으로 연결.
- 실전 진입은 연습 튜토리얼을 자동 표시하지 않으며 재마운트 후에도 목적을 유지한다. 실전 화면에서 같은 상황의 연습을 시작할 수 있다.
- 기초 훈련은 복기에서 연결. 메시지 답장은 더보기로 이동.
- 더보기는 메시지 답장·용어 노트·AI 대화 상대·사용/저장 안내. 각 화면의 복귀 경로 및 제목 통일.
- 일상 대화·AI 요청 연습의 신규 주 메뉴 진입 제거. 기존 기록/주소는 유지하고 홈의 최근 추천에서 제외.
- 관찰·커뮤니티 미리보기, 확장 예정 목록과 레거시 연습 안내 링크 제거.
- 내 기록의 상황 선택 버튼 이름 수정. 연습 상세→내 기록 복귀 시 부모 메뉴와 URL도 동기화. 이탈 취소 시 입력 유지.

## 운영 확인과 한계

공개 HTTP 요청: `/` 200, `/api/coach` 200. Gemini available/voiceAvailable=true, configurationStatus=configured, model=gemini-2.5-flash, sampleOnly=true. 실제 생성 성공을 의미하지 않는다.

검토 중 받은 공개 JS에는 ‘저장한 상대와 대화 연습하기’가 있고 직전 소스 홈 ‘어떤 연습을 해볼까요?’와 이번 수정 문구 ‘연습할 상황 고르기’는 없었다. 운영이 최신 IA로 배포됐다고 판단하지 않는다. 본 점검은 HTTP·정적 파일 검사이며 실제 화면 상호작용 검증이 아니다.

Render 설정은 autoDeployTrigger=off. 최신 커밋을 배포하는 관리 연결이 현재 없으므로 운영 반영을 수행하지 못했다. 배포 권한 보유자가 `deploy-render-20260917` 최신 커밋으로 Manual Deploy 후 주요 화면을 확인해야 한다.

실제 브라우저 검증은 앞선 자동 승인 검토 사용량 제한으로 차단되어 모바일 렌더링·키보드·마이크·OS 클립보드·실제 AI 실전 도움·지연 및 연습/복기 경로는 미완료다. 다른 브라우저 수단으로 승인 실패를 우회하지 않았다. 사용성 개선 효과를 측정했다고 주장하지 않는다.
