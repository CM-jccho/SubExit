## 1. 검사 준비 · 3분

- 실제 개인정보 없이 아래 가상 문장만 사용합니다. 기존 개인 기록을 삭제하지 마세요.
- 첫 방문은 새 브라우저 프로필이나 시크릿 탭에서 확인합니다. 기록 유지 검사는 일반 창의 별도 QA 기록으로 진행합니다.
- PC Chrome: 1366×768 수준의 창, 키보드 Tab/Shift+Tab/Enter/Escape. 가능하면 Safari도 주요 경로를 반복합니다.
- iPhone Safari: 실제 기기의 키보드·마이크·오디오를 확인합니다. PC의 모바일 크기 흉내는 이를 대체하지 않습니다.
- 카카오톡에서 같은 링크를 열어 음성·키보드·입력 대체 경로를 추가 확인합니다. Android를 제출 지원 범위에 포함하면 Android Chrome도 반복합니다.
- 작은 화면: 360×640에서 온보딩·모달·하단 버튼 접근성을 확인합니다. 실제 기기가 없으면 이 항목은 ‘미검증’입니다.
- 각 결과에 기기/브라우저/주소/시간과 통과·실패·미검증을 기록합니다. 목표 시간 약 45~60분이며 기기별 반복과 업로드 길이에 따라 늘어납니다.

## 5. 판정 및 실패 기록

- **제출 보류:** 핵심 버튼 무반응, 키보드로 주요 행동 접근 불가, 음성 재생/문자 변환 실패가 안내 없이 방치됨, 잘못된 상황 답변, 기록 유실·중복, 샘플을 AI라고 표시, 실제 AI 핵심 기능 미확인 또는 제출 주소 미배포.
- **제한 명시 후 판단:** 인앱 브라우저 음성 API 미지원처럼 대체 입력이 정상인 경우. 지원 브라우저와 제한을 제출 설명에 명시합니다.
- **통과 기준:** P01~P12를 PC와 실제 모바일의 해당 입력 방식에서 통과하고, E 항목의 실패 복구가 정상이어야 합니다. 지원하지 않는 항목은 이유를 적고 별도 판단합니다. 자동 테스트 개수로 이를 대체하지 않습니다.
- 이미지 품질·여백의 작은 차이는 핵심 흐름을 막지 않으면 후속 개선으로 분리합니다.
- 각 AI 요청의 클릭→결과 표시 시간을 기록하세요. 느리더라도 로딩/취소/오류 피드백이 있는지 함께 판단합니다. 한 번의 응답 속도를 평균 성능으로 소개하지 않습니다.

## 6. 현재 Vercel 상태와 남은 작업

연결과 최신 소스 배포는 확인했습니다. 별도 프로젝트 생성이나 계정 재연결은 필요하지 않습니다. Gemini 키도 설정되어 있습니다. `configured`는 키 유효성·잔여 한도·실제 생성 성공의 증거가 아닙니다.

제출 전 이 주소에서 P03/P04, P09~P11 및 모바일 E01~E03을 실제로 통과해야 합니다. 샘플 성공을 AI 생성 성공으로 기록하지 마세요. 이전 체크 문서의 Render 주소·Vercel 미연결 상태는 현재 운영 상태가 아닙니다.
