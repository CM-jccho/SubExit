# 영역별 대화 트레이닝

## 사용 흐름

‘내 대화 → 기초 훈련’ 또는 복기의 ‘이 복기에서 기초 훈련 시작’으로 진입한다. 상위 메뉴는 추가하지 않는다.

| 영역 | 훈련 방법 | 소재 |
|---|---|---|
| 생각 넓히기 | 소재 → 경험·취향 → 상대에게 건넬 질문 | 점심, 비 오는 날, 새 동료와 출근길 |
| 질문 이어가기 | 실제 단서 → 짧은 반응 → 질문 하나 | 산책, 새 취미, 모호한 업무 요청 |
| 핵심 전달 | 핵심 → 이유 → 요청 | 검토 부탁, 약속 변경, 업무 우선순위 |

각 영역은 시작 2개·응용 1개로 구성한다. 난이도는 사용자가 고르며 자동으로 능력을 판단하지 않는다. 1~3분은 사용 흐름의 목표 시간이며 시간제한은 없다.

1. 방법과 가상 상황을 읽고 세 칸에 직접 작성한다. 막히면 작성된 예시를 펼친다.
2. ‘저장하고 다듬기’를 누르면 첫 표현을 저장한다. 준비된 확인 기준으로 검토하거나 선택적으로 AI 피드백을 받는다.
3. 마무리 표현을 저장하면 처음·마무리 표현을 비교한다. 원래 표현을 유지한 경우도 그렇게 표시한다.
4. 복기에서 들어왔다면 ‘원래 장면에서 다시 연습’으로 원래 목표·지킬 선·상대 발화를 유지한 재연습을 생성한다.

## AI와 저장

AI는 고정된 훈련 상황과 첫 답변 세 개만 전달받는다. 다른 대화·복기 원문·연결된 기록 정보는 자동 전송하지 않는다. 피드백은 답변에 실제 포함된 연속 구절을 인용해야 저장된다. 점수·성격·지능·심리 진단은 제공하지 않는다. 인용 검증이 피드백의 모든 해석이 정확함을 보장하지는 않는다.

일일 한도·연결 실패·시간 초과 시 입력과 이전 기록은 유지하며 작성된 확인 기준으로 완료할 수 있다. 실패를 AI 성공으로 대체하지 않는다. 첫 표현을 다시 저장하면 이전 AI 피드백을 무효화한다. 저장된 피드백은 재열기 때 다시 생성하지 않는다. 화면 이탈 시 진행 중인 AI 요청을 취소하고 늦은 응답을 저장하지 않는다.

브라우저 IndexedDB에 첫 표현·마무리·선택적 AI 피드백·원래 복기 연결을 저장한다. 기록 삭제 기능을 제공한다. 저장 버튼 전의 입력은 자동 저장하지 않으며 기기 간 동기화도 제공하지 않는다. 완료한 고유 소재 수를 표시하지만 대화 능력 점수나 기존 연습 보상으로 계산하지 않는다.

원래 대화가 삭제됐거나 대화·복기가 달라지면 오래된 연결로 재연습하지 않고 안내한다. 훈련 자체의 기록은 유지한다.

## 검증

111개 자동 테스트: 기존 102개에 아래 9개 검증을 추가했다.

- AI 입력 검증·다른 대화 격리·실제 표현 인용 검증
- AI 없이 첫 표현과 수정 표현 저장·재열기·삭제·보상 미지급
- 한도 초과 후 입력 보존과 자체 검토 완료
- 첫 표현 변경 시 AI 피드백 무효화
- 원래 장면의 목표 유지·삭제 및 변경된 복기 거부
- 복기 → 추천 영역 → 훈련 완료 → 같은 장면 재연습 통합 흐름
- 화면 주소로 직접 진입 및 상위 메뉴 유지
- AI 피드백 저장·재열기 시 재호출 방지·이탈 후 늦은 응답 차단
- 저장 실패 시 편집 내용 유지 및 중복 없는 재시도

제공자 응답은 자동 테스트에서 모의 응답으로 검증한다. 실제 AI 해석의 품질과 장기적인 훈련 효과는 별도 사용자 검증 대상이다. 이번 훈련 입력은 문자 기반이며 별도 음성 녹음을 추가하지 않는다.
