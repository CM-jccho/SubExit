# 홈 단순화와 제품 주제 검토

기준일: 2026-09-17. 기준: 사용자 승인 B안, main `52627ee`, 실제 운영 홈과 저장소 구현. 경쟁 서비스·외부 시장 평가는 범위 밖이다.

## 결론

[확정] 제품의 중심은 **내 상황으로 대화 연습 → 실제로 한 말을 근거로 복기 → 같은 장면 재연습**이다. 말과 문자 모두 입력 방식이며, 음성 기능 자체가 제품의 목적은 아니다.

[해석] 핵심 기능은 구현돼 있지만 홈에서 모든 기능을 동등하게 소개해 제품 주제가 희석됐다. 자유 대화·캐릭터 공간·일상 루틴·프롬프트 훈련은 각각 쓸모가 있어도, 첫 방문에서 대화 연습의 가치가 보이기 전에 선택지를 늘렸다. 이번에는 기능 추가가 아니라 중심 흐름과 보조 기능의 노출 우선순위를 정리했다.

## 근거와 반영

- 홈: 관심 상황 표시, 연습 소개, 시작 버튼, 샘플 소개, 샘플 카드, 전체보기 두 곳, 녹음/메시지 카드, 다른 방식, 가이드, 저장 설명이 함께 있었다. 이제 관심 상황 → 관련 장면 최대 2개 → 내 상황 만들기/전체보기로 줄였다. 개인 카드가 있으면 최근 1개만 함께 표시한다.
- 초기 선택: 그림과 네 가지 상황을 유지하고, 반복 설명을 줄였다. 선택을 바꾸는 동안 아래 연습 내용은 계속 숨긴다. 삭제한 샘플을 다시 만들지 않는다.
- 메뉴: 홈 / 내 대화 / 녹음·기록 / 메시지 답장 / 더보기. 녹음과 메신저의 독립 접근을 유지한다. 더보기에서 용어 노트, 기초 훈련, AI 대화 상대, 일상 대화, AI 요청 연습, 사용·저장 안내를 찾을 수 있다. 기존 직접 링크도 유지한다.
- 복기: 고쳐 말할 문장과 이번 연습의 초점을 먼저 제시한다. 실제 인용과 AI 해석은 ‘내 말에서 근거 보기’로 펼친다. 같은 장면 재연습이 주 행동이며 기초 훈련은 별도 펼침 안에 둔다. 근거 데이터나 재연습 맥락을 삭제하지 않는다.
- 소개: 페이지 메타데이터와 카드 상세 소개도 연습·복기·재연습으로 맞췄다. 보관 상태, 녹음 실패, 한도 안내, 동의와 입력 내용은 숨기지 않는다.

## 기능별 주제 적합성 판단

핵심: 상황/목표/지킬 선 설정, AI 상대 역할 대화, 실제 발화 근거 복기, 같은 장면 재연습. 사용자가 답변을 직접 해보고 바꾸는 흐름을 제품 소개와 시연의 맨 앞에 둔다.

인접 기능: 녹음 분석과 메시지 답장. 실제 겪은 대화와 앞으로 보낼 답변을 개선하므로 주제와 맞는다. 다만 현재 모든 녹음·메시지 결과가 같은 장면의 역할 연습으로 자동 연결되는 것은 아니다. 이를 통합 완료로 소개하면 안 된다. 녹음은 2분·2.4MB 이내 입력, 문자 수정·화자 확인 후 코칭이며 연속 통화 분석이 아니다.

보조 기능: 용어 노트, 의사소통 팁, 기초 훈련. 실제 연습에서 발견한 부족한 표현과 기술을 보완할 때 연관성이 강하다. 이번에는 찾을 수 있는 위치를 유지하면서 홈의 독립 홍보를 덜었다.

주제가 멀어질 수 있는 기능: AI 요청 연습, 자유 대화, 캐릭터 방 꾸밈과 날씨, 커뮤니티 미리보기, 에이전트 대본 관찰. 대화와 관련은 있지만 핵심 효용을 증명하지는 않는다. 보조 메뉴에서 이용하고, 해커톤 주 시연에 모두 나열하지 않는 편이 좋다. 기존 샘플 표시는 유지한다.

캐릭터와 보상: 상대나 처리 상태를 이해하는 장치, 수행 기록으로 사용한다. 캐릭터 수집이나 점수 자체를 대화 실력 향상의 증거로 설명하지 않는다.

## 권고하는 제품 소개와 시연

“어려운 대화를 미리 해보고, 내가 한 말에서 고칠 부분을 찾은 뒤 같은 장면을 다시 연습하는 대화 코치.”

시연은 직장 동료에게 검토를 부탁하는 한 장면으로 고정한다. 상황과 목표 확인 → 내 답변 두 번 → 발화 인용과 개선 문장 확인 → 동일 맥락에서 다시 답하기 순서다. 녹음/메시지는 확장 입력 경로로 짧게 소개하고, 미구현 기능을 현재 가치에 포함하지 않는다.

## 검증 및 남은 항목

- 테스트 129개 통과. 추가 검증: 홈의 전체보기 1개, 추천 장면에서 상세 진입, 5개 주 메뉴, 보조 기능 접근, 용어 노트 새로고침 복원, 기존 직접 URL 유지, 빈 상황에서 직접 만들기.
- 복기 근거 기본 접힘/펼침과 인용 확인, 저장된 복기 재사용, 원래 목표·지킬 선을 가진 재연습 생성 확인.
- 프로덕션 빌드 및 타입 검사 통과. 테스트는 모의 AI 응답으로 UI/저장 연결을 검증한다.
- PR #54는 main에 병합했으나 Vercel이 build-rate-limit으로 배포를 거부했다. 운영 시각 검증은 새 배포 후 필요하다. 실제 휴대폰 터치·마이크 품질 및 사용자 이해도 관찰은 별도 확인이 필요하다.
- [P1, 확인 필요] 정확한 인용과 타당한 코칭은 다르다. 실제 모델에서 목표 유지·부정어·무리한 약속을 평가해야 한다. 이번 UI 변경으로 AI 품질이 입증된 것은 아니다.
- [P2, 후속 권고] 잘한 점이 필수인 복기 계약에서 근거 부족 시 판단 보류를 허용하는 개선은 별도 작업이다.
- [후속 권고] 신규 사용자가 안내 없이 장면을 고르고, 복기 근거를 열고, 다시 연습까지 할 수 있는지 관찰한다. 문구 감소를 이해도 향상의 측정 결과로 표현하지 않는다.
