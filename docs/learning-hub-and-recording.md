# 대화 방식·용어·언어·녹음 코칭 보강

## 짧은 녹음 코칭

1. 음성 기록에서 새 녹음을 열고 파일을 첨부한다. 원본 재생으로 녹음을 확인한다.
2. AI 전송 동의 후 문자 변환하거나, 변환이 실패하면 직접 문자를 적는다. 음성과 문자를 기록에 추가한다.
3. `이 녹음으로 대화 돌아보기`에서 변환된 문자를 수정한다. 말하는 사람이 바뀔 때마다 줄을 나눈다. 원본은 덮어쓰지 않는다.
4. 각 줄을 `내 말` 또는 `상대 말`로 지정한다. 자동으로 두 화자가 번갈아 나온다고 가정하지 않는다. 3명 이상이면 한 상대와 나눈 장면만 남긴다.
5. 상대·상황·원하는 결과·지킬 선을 확인한다. 화자 확인 체크와 AI 전송 동의는 구분한다.
6. `/api/recording-review`는 확인한 문자와 화자·맥락만 받아 코칭한다. 음성 원본은 다시 보내지 않는다.
7. 실제 내 발화에서 인용한 잘한 점·개선점·고쳐 말할 문장·다음 연습 행동을 보여준다. 서버는 인용문이 지정한 내 발화에 실제 포함되는지 검증한다.
8. 개선할 발화 직전의 상대 말을 가져와 새 연습을 만든다. 앞에 상대 말이 없으면 이유를 안내한다.

제한: 한 번에 2~40개 발화, 문자 합계 4,000자. 한 기록에는 선택한 음성 한 개의 코칭을 저장한다. 원문이 바뀌면 이전 코칭을 재사용하지 않고 다시 확인한다. 자동 화자 분리, 정밀 타임스탬프, 억양·감정 평가, 장시간 파일 처리는 이번 범위에 없다.

저장: 원본 음성·변환 문자·확인한 수정본·화자·맥락·코칭은 이 브라우저 기기에 보관한다. 문자·화자 편집은 저장/다음 버튼을 눌러야 보관된다. 코칭 요청 직전 확인한 초안도 저장하므로, 한도·연결 오류 후 이어서 시도할 수 있다. 계정 간 동기화나 서버 녹음 보관 기능은 없다.

녹음 예시 3개(부탁·업무 범위·가족 표현)는 실제 음성 파일이 없는 가상의 문자와 사전 작성 코칭이다. 현재 사용자의 녹음을 분석한 결과로 대체하지 않는다. 예시를 여는 데 AI 호출은 없다.

## 언어 설정과 예비 응답

새 대화에서 상대 언어와 내 답변 후보 언어를 별도로 고른다. 예: 상대는 English, 내 후보는 한국어. 입력은 원하는 언어로 할 수 있다. 실제 외국인과 연결하는 기능이나 실시간 통역은 아니다.

설정은 연습 기록과 재연습에 유지된다. 음성 변환은 원어를 유지하도록 지시한다. 읽어주기는 브라우저에 설치된 음성과 지원 범위에 영향을 받는다. 실시간 코칭의 언어 설정 및 앱 전체 번역은 이번 변경에 포함하지 않는다.

한국어 128개 예비 문장과 별도로 영어·일본어 일반 대화 예시를 각 9개 추가했다. 외국어 예비 응답도 샘플 출처·오류 이유를 유지하며, AI 호출 없이 사용하는 수동 샘플 모드에서 체험할 수 있다. 예비 응답은 실제 상황에 대한 분석이 아니므로 사용자가 고쳐 쓰는 전제다.

## 용어와 가상 역할의 기준

분야: IT·개발, 기획·디자인, 마케팅·콘텐츠, 영업·고객 응대, 유통·이커머스, 물류·제조, 재무·회계, 인사·조직, 외식·카페, 영상·제작, 학교생활, 10대·온라인 표현, 게임·커뮤니티, 영어, 일본어.

모든 10대가 같은 표현을 쓰거나 특정 표현이 최신 유행이라고 단정하지 않는다. 학교생활 표현과 은어를 구분하고, 사용한 사람에게 맥락을 물어보도록 안내한다. 하루는 가상의 AI 역할이며 실제 학생·개인 경험·세대 전체의 대표성을 주장하지 않는다.

예시는 사용자가 선택해 노트에 저장한다. 기존 노트를 덮어쓰지 않고 같은 분야·용어가 있으면 기존 메모를 연다. 공유 가이드에는 예시 출처와 직접 확인 여부를 표시한다. 실제 대화의 원문과 음성은 가이드 공유 대상에 포함하지 않는다.

## 검증

- 기존 65개 테스트에 녹음 입력·인용 검증, 저장·재연습, 언어 프롬프트 전달, 외국어 예비 응답, 용어 데이터, 녹음 UI 오류 회복, 화자 재확인, 익명 라운지, 분야 필터, 자유 입력 전환 테스트 11개를 추가했다.
- 오류 시나리오 480건은 기존 모의 응답 행렬에 포함된다. 실사용자의 대화나 실제 모델 응답을 480회 수집한 것이 아니다.
- 실제 마이크 품질·발화 인식 정확도·언어별 코칭 품질은 별도 실측이 필요하다.
