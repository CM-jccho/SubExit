# 첫 행동과 기능 명칭 정리

기준: main 1f2331f, 사용자 피드백(첫 행동·친구방·녹음/실시간 구분·대화 연습·용어 노트 공개 범위).

## 문제와 반영

- 홈에 동등한 시작 버튼이 많았다. ‘대화 연습 시작’ 하나를 주요 행동으로 두고 녹음 분석·메시지 답장을 보조 선택으로 배치했다. 일상 대화·AI 상대·짧은 힌트는 ‘다른 방식으로 대화하기’에 접었다. 샘플 카드와 튜토리얼은 유지했다.
- 친구방은 공간의 성격만 알려줬다. 메뉴·제목·관련 도움말을 ‘AI 대화 상대’로 통일했다. 캐릭터 선택으로 새 대화·지난 기록·역할 설정을 연다는 설명과 실제 이용자가 아니라는 구분을 추가했다.
- 녹음 분석은 끝난 대화의 파일→문자·화자 확인→코칭으로, 대화 중 힌트는 최대 8초 녹음→다음 한마디로 구분했다. 연속 실시간 처리라고 표현하지 않는다.
- 기존에도 좌우 말풍선이 있었지만 입력이 접혀 있고 복기·보상이 입력보다 앞에 있었다. 연습·자유 대화에서는 문자 입력을 기본으로 열고, 보낸 뒤에도 유지한다. 대화 배경·말풍선을 정돈하고 복기·보상을 입력 뒤로 옮겼다. 음성 입력과 오류 복구는 유지한다.
- 용어 노트에는 ‘나만 보는 노트 · 이 브라우저에 저장’을 표시한다. 다른 이용자에게 자동 공개되지 않으며, 선택한 가이드의 공유 창 또는 파일 전달만 지원한다. 공유 시 뜻·예문·주의사항·메모가 포함되고 원문·음성은 제외된다. AI 설명 요청 시 선택한 용어·분야·문맥은 Gemini에 전송한다. 계정 동기화가 없고 브라우저 데이터 삭제 시 기록도 지워질 수 있음을 안내한다.
- ‘소통 팁’ 탭에 부탁·확인 질문·거절·메신저 응답·후속 질문·실수 수습 예시 6개를 추가했다. 직접 작성한 예시임을 표시하고 내 노트에서 수정 후 저장한다. 같은 팁을 다시 담으면 기존 메모를 연다. 전문성·성숙함의 등급이나 효과를 보장하지 않는다.
- 미구현 기능은 사용 화면에서 제거하고 안내의 접힌 ‘앞으로 검토하는 방향’으로 모았다. 출시 약속이나 공개 일정이 있다는 인상을 피했다.

## 검증

- 자동 테스트 122개 통과: 기존 API·녹음 상태·저장·한도 초과·대화/메신저 흐름 포함.
- 이번 회귀 검증: 연속 문자 답장 입력, 입력→보상 순서, 소통 팁 저장 전 초안·중복 방지·수정 메모 보존, 명칭 변경 후 팝업 복귀.
- Next.js 프로덕션 빌드 및 타입 검사 통과.
- 배포 후 공개 화면에서 홈 이동, AI 상대 설명, 말풍선과 입력, 소통 팁 수정·저장·재진입을 확인한다.

## 남은 검증

- 실제 iOS/Android에서 한글 키보드·마이크·파일 선택·가로 넘침 확인.
- 처음 접하는 사용자가 안내 없이 연습을 시작하고, 녹음 복기와 짧은 힌트를 구분하는지 관찰. 이번 변경만으로 이해도가 개선됐다고 단정하지 않는다.
- 이번 변경은 UI·정적 콘텐츠이며 실제 AI 답변 품질을 새로 측정하지 않았다.
