# 새싹과 연습 퀘스트

제품 중심은 대화 연습 → 복기 → 같은 장면 재연습이다. 친구방의 작은 선반과 홈 진입 버튼에서 보상을 확인한다.

## 지급과 사용

- 직접 작성하거나 후보를 고친 답변 두 개: 물방울 2개.
- 실제 내 발언 한 개를 선택해 다른 문장으로 고쳐 쓰고 저장: 1개. AI 분석 없이도 가능하다.
- 복기에서 가져온 같은 장면에 원래 답변과 다른 새 답변을 저장: 3개.
- 각 보상은 원본 대화와 연결된 재연습 전체에서 종류별 한 번이다. 재연습 버튼 반복, AI 재응답, 기록 재저장으로 중복 지급하지 않는다.
- 사전 작성 기록, 빈 문장, 후보를 그대로 보낸 답변, 재연습에 복사된 기존 발화는 집계하지 않는다. 샘플 상대와 연습하더라도 사용자가 직접 쓴 답변은 인정한다.
- 살구빛 화분·머그컵·별빛 장식을 각 물방울 2개로 교환한다. 소품 보관/다시 놓기는 무료이며 환불·재구매를 반복하는 구조가 아니다.
- 누적 6개에 새싹, 12개에 성장, 24개에 꽃. 사용 가능한 잔액과 누적 성장량을 구분하며 방문하지 않아도 감소하지 않는다. 일일 출석이나 순위 경쟁은 없다.

## 저장

기존 IndexedDB의 meta 저장소에 버전 식별자가 있는 보상 원장을 저장한다. 발화 저장과 보상 지급은 같은 트랜잭션이다. 교환도 단일 readwrite 트랜잭션에서 잔액을 읽고 차감하므로 여러 탭의 동시 교환으로 초과 사용하지 않는다. 실패 시 지급·차감 성공으로 표시하지 않는다.

원장에는 원본 대화 ID·행동 종류·금액, 소유/배치 소품만 저장하며 발화 원문은 복제하지 않는다. 직접 복기한 문장은 원래 대화 기록에 저장한다. 기록 삭제로 이미 얻은 물방울을 회수하지 않으며 같은 ID를 다시 저장해도 보상을 재지급하지 않는다. 브라우저 데이터 삭제 시 보상도 사라지고 기기 간 동기화는 없다. 실제 결제·현금 가치·서버 기반 부정 사용 방어는 제공하지 않는다.

## 범위와 검증

현재는 세 가지 반복 가능한 연습 행동과 소품 세 개다. 개인화한 AI 퀘스트 생성, 용어 사용 평가, 일일 미션은 추가하지 않았다. 보상은 연습 행동의 기록이며 대화 실력 향상을 인증하는 점수가 아니다.

86개 테스트와 프로덕션 빌드로 확인한다. 추가 테스트는 중복 저장·재연습 원본 연결·샘플 제외·복사 발언 제외·수정 전후 검증·동시 교환·소유 유지·삭제 후 성장 유지다. 실제 브라우저 확인 결과는 배포 후 별도 기록한다.
