# 모바일 UI·연속 자막·긴 녹음 개선

## 변경 범위

- 모바일 하단 메뉴를 3개 균등 열로 통일하고 중복 CSS를 제거했다. 홈 버튼과 하단 안내 사이 여백 및 safe-area를 확보했다.
- 홈의 세 단계 아이콘 카드는 한 줄 순서 안내로 축소했다.
- 지원 브라우저에서 Web Speech API의 연속 인식과 중간 자막을 사용한다. Gemini 코칭 요청 중에도 인식을 유지하며, 확정 문장에 대한 코칭 요청은 최소 6초 간격으로 합쳐 처리한다. 기존 짧은 녹음·직접 입력도 유지한다.
- 녹음 복기 파일 한도를 50MiB·30분으로 확장했다. 긴 파일은 브라우저에서 45초 단위의 mono 16kHz PCM WAV로 변환하여 순서대로 전송한다. 원본 파일을 변경하지 않으며 이미 압축된 MP3보다 전체 전송량이 작아진다는 보장은 없다.
- 구간별 변환 결과를 보관하며 실패한 뒤 완료한 구간 다음부터 재개한다. 저장된 기록은 진행 상황도 IndexedDB에 저장한다. 저장 전 입력은 현재 화면에서 유지한다.
- TXT/SRT/VTT 가져오기, 텍스트 60,000자·600개 발화, 화자 지정 20개씩 표시를 지원한다. 화자는 자동으로 교대로 추정하지 않는다.
- 중요 용어 추출 시 텍스트 앞부분만 자르던 동작을 제거했다. 결과·오류를 해당 발화 아래 표시하고, 결과 용어를 눌러 저장할 수 있다.
- 직접 스크랩은 선택한 원문을 사용하거나 표현을 직접 입력하여 AI 동의 없이 저장할 수 있다. 뜻·뉘앙스 AI 보강은 별도 동작이다.

## 추가 이미지 피드백 반영

- 한 번 확인한 Gemini 전송 동의는 같은 페이지 이용 중 기능·기록 간 공유한다. 상단 ‘AI 동의 완료’에서 열람·철회한다. 메모리로만 유지하며 새로고침·종료 시 초기화한다. 실시간 브라우저 음성 인식 및 공개 검색의 별도 전송 동의는 범위가 달라 유지한다.
- 대화 연습의 후보 요청·선택·수정·전송을 대화 바로 아래 같은 입력 영역 안에서 처리한다. 녹음 기록 작성은 기존 입력 대화상자를 유지한다. 보내지 않은 답변을 두고 이동할 때 확인한다.
- 상대와 내 말풍선의 좌우 정렬·꼬리·색상을 강화하고, 출처와 오류 안내는 펼칠 수 있는 작은 배지로 표시한다. 원래 샘플 출처 데이터는 그대로 보관한다.
- ‘이번 장면의 연습 기록’은 ‘내 답변 돌아보기’로 정리하고, 자동 저장 및 ‘내 기록’에서 다시 열 수 있다는 설명을 추가했다. 해당 화면의 꾸미기 티켓 문구·방 이동 버튼을 제거했다. 기존 사용자 보상 데이터는 변경하지 않는다.

## 검증

- `npm test`: 163개 통과, 실패·건너뜀 없음.
- `npm run build`: 프로덕션 빌드, 타입 검사, 정적 페이지 생성 완료.
- 연속 음성 인식 모의 이벤트, 중간 자막, AI 처리 중 인식, 중단·백그라운드 이동·권한 거부, 늦은 응답 무시를 검증했다.
- WAV 헤더·구간 범위·전송 크기, 실패 후 재개·취소, 텍스트/자막 가져오기, 100개 발화 분석, 긴 텍스트 끝부분 용어 추출, AI 없는 직접 스크랩 저장을 검증했다.
- 모바일 CSS 소유권 및 버튼/안내 간격을 코드 테스트로 검증했다. 실제 휴대폰의 safe-area·키보드 및 실물 마이크는 이 실행 환경에서 검증하지 못했다.
- 실제 30분 녹음의 음향 품질·브라우저 메모리 사용량은 미검증이다. 분할 경계에서 인식이 부정확할 수 있으므로 사용자가 전사 내용을 검토한다.

## 동작 한계와 근거

연속 인식은 브라우저와 음성 인식 서비스 지원에 의존한다. 서비스 연결 종료 시 재연결하며 화면을 벗어나면 중지한다. 화자 분리, 시스템 통화 음성 캡처, Gemini Live API, 언어 번역은 이번 구현 범위가 아니다. 자막은 인식 결과 도착 시 표시되며 코칭에는 확정 문장 대기·요청 간격·AI 응답 지연이 추가된다.

- [MDN SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition)
- [MDN interimResults](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/interimResults)
- [MDN continuous](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/continuous)
- [Gemini Live API (日本語)](https://ai.google.dev/gemini-api/docs/live-api?hl=ja): 향후 브라우저 인식 의존도를 줄이는 별도 스트리밍 구현의 참고 자료.
