1. 제품의 중심 — 원래 아이디어로 복귀

대화·통화 중 말문이 막히는 순간, 내 상황과 목표에 맞는 다음 한마디를 돕는 AI. 평소에는 같은 상황을 미리 연습한다.

[확정] 사용자 재확인: 제품의 중심은 ‘대화 연습’보다 실제 대화·통화 도중 도움을 주는 것이다. 연습과 복기는 평소 준비하는 보조 흐름이다. 앞서 제안했던 ‘네 가지 동등한 목적’과 ‘연습만 중심’ IA를 모두 이 기준으로 수정한다.

주 대상은 부탁·거절·일정 조율·고객 응대처럼 대화 중 바로 적절한 말을 찾기 어려운 성인이다. 핵심 질문은 ‘다음에 뭐라고 말하지?’다. 음성과 문자는 상대 말을 전달하는 두 입력 방법이다.

제품 목적과 현재 구현을 구분

  • 목적: 상황에 맞는 대화 중 도움, 그리고 평소 같은 상황의 연습.
  • 현재 구현: 상대 말을 최대 8초씩 녹음하거나 문자로 입력 → 인식 내용 확인 → 목표에 맞는 다음 문장 제안. 대면 또는 다른 기기의 스피커폰 옆에서 사용한다.
  • 현재 제한: 처리 중에는 마이크가 꺼진다. 같은 휴대폰의 통화 음성 직접 접근, 상시 청취·연속 스트리밍은 제공하지 않는다. ‘실시간’이라는 표현만으로 끊김 없는 통화 코치처럼 소개하지 않는다.
  • 실전 입력·결과는 현재 화면 상태이며 통화 전문/힌트 이력으로 자동 저장되지 않는다. 저장한 상황 카드는 재사용할 수 있다. 별도 녹음 기록·평소 연습 기록은 저장 기능이 있다.
  • 무료 Gemini의 현재 시연 조건은 개인정보·기밀 없는 가상/자작 대화다. 실제 민감한 통화에 바로 적용 가능한 운영 완성품으로 설명하지 않는다.

AI와 주제의 핵심 연결

단계사용자의 문제AI 역할코드의 검증·연결
상황 준비누구와 무엇을 지켜야 할지 설명해야 한다자유 설명에서 상대·목표·지킬 선 초안 정리사용자 확인 후 카드 저장·재사용
지금 대화 입력상대가 방금 말한 내용을 놓치거나 정리하기 어렵다짧은 음성을 문자로 변환인식한 문장을 사용자가 확인·수정; 실패 시 원음 유지
다음 한마디 제안즉석에서 내 의도에 맞게 말하기 어렵다상대 말과 저장한 목표·지킬 선·말투를 함께 반영한 답변 제안원문 인용 검사, 출처·지연·실패 상태 표시
평소 대비같은 상황에서 반복해서 막힌다AI가 상대 역할을 맡아 대화하고 실제 사용자 발화의 개선점 제안같은 상황 설정 재사용, 근거 확인, 기록, 재연습 연결

[해석] 일반적인 채팅과의 차이를 보여줄 단위는 ‘저장한 상황과 지킬 선이 실전 답변에 어떻게 반영되는가’와 ‘그 설정을 평소 연습에도 쓸 수 있는가’다. 응답 지연과 도움의 적절성은 실제 요청으로 검증해야 한다. 인용이 원문에 있다는 사실만으로 제안이 적절하다고 보장하지 않는다.

3. IA — 화면과 소유 관계

주 메뉴

  • 홈: 지금 대화 도움받기(주 행동) / 미리 연습하기(보조 행동). 최근 개인 기록 한 건.
  • 내 기록: 저장한 연습·녹음·답장을 찾아 재열기. 실전 통화 전문 자동 기록 메뉴가 아님.
  • 더보기: 메시지 답장·용어 노트·AI 대화 상대·사용·저장 안내.

핵심 하위 구조

  • 실전: 홈 → 지금 대화 도움받기 → 상황 선택/작성 → 목표·지킬 선 확인 → 전송 안내 → 상대 말 입력 → 인식 내용 확인 → 다음 한마디 → 다음 구간 입력.
  • 평소: 홈 → 미리 연습하기 → 같은 상황 선택/작성 → AI 상대와 직접 대화 → 근거 복기 → 같은 장면 재연습.
  • 연결: 실전 도움 화면의 ‘이 상황 미리 연습하기’ → 같은 카드의 역할 연습. 실전 통화 전문을 자동 이관하는 기능은 아니다.
  • 사후: 내 기록 → 녹음·파일 추가 → 문자 수정·화자 확인 → 복기 → 연습.
  • 보강: 평소 연습의 복기 → 필요한 기술 훈련 → 원래 연습 장면으로 복귀.

두 경로가 공유하는 것은 상황 카드다. 상황을 선택한 뒤 실전 사용자가 연습 시작 화면으로 잘못 들어가지 않도록 진입 목적을 유지한다. 서로 다른 전체 기능 목록을 반복해서 보여주지 않는다.

화면 이동과 URL 정책

  • 실전 진입은 ?view=library&purpose=live로 목적을 유지한다. /?live=1도 실전 상황 선택으로 진입한다. 새로고침 후 상황을 다시 선택해도 실전 도움으로 이어진다. 연습은 ?view=library로 구분한다.
  • 실전 경로에서는 연습용 튜토리얼을 자동으로 열지 않는다. 도움말에서 사용자가 직접 시작할 수 있다.
  • 홈·목록·더보기 도구는 ?view=...로 재진입한다. 알려지지 않은 view는 홈으로 보낸다.
  • 상황 작성·상세·짧은 코칭은 새로고침 시 상황 목록으로 돌아간다. 진행 중 역할 대화·자유 대화·녹음은 기록 목록으로 돌아간다. 개별 기록 ID까지 URL에 복원하지는 않는다.
  • 기록에서 열어 본 답장·훈련은 ‘내 기록’ 소속으로 유지한다. 신규 메시지 답장은 더보기 소속이다.
  • ‘내 기록으로’를 누르면 콘텐츠뿐 아니라 URL·선택된 주 메뉴도 내 기록으로 함께 전환한다. 미전송 입력의 이탈 확인은 유지한다.
  • 화면 뒤로가기와 새로고침은 동일 동작이 아니다. 미전송 초안은 브라우저 종료·새로고침 후 복원을 보장하지 않는다.
  • 관심 분야 변경과 ‘모든 분야 예시’는 구분한다. 전체 예시를 잠시 보는 동작으로 저장된 관심 설정을 바꾸지 않는다.

레거시 API /api/analyze(이전 구독 화면 분석)와 /api/analyze-call도 저장소에 남아 있으나 현재 핵심 IA의 사용자 진입이 아니다. 의존성에 남은 Anthropic/OpenAI SDK를 현재 핵심 도움 기능의 운영 모델로 소개하지 않는다. 엔드포인트 제거·정리는 별도 호환성 점검 후 진행한다.

5. 공통 기능 정책

데이터·공개 범위

  • D-01 상황 카드: 역할·상대·목표·상황·지킬 선·말투·상대 선택, 생성/수정/최근 사용 정보. localStorage. 설정 대화 전문은 저장하지 않음.
  • D-02 대화 세션: 사용자·상대 발화, 음성 Blob, 파형, 언어, 맥락, 복기, 재연습 원본 연결, 답장/훈련 결과. IndexedDB의 sessions.
  • D-03 용어 노트: 용어·업종·뜻·예문·주의·메모·원문 인용·세션 ID·AI/수동 출처. IndexedDB의 terms. 타인에게 자동 공개되지 않음.
  • D-04 설정: 관심 상황·상대 설정·가이드 완료 등의 localStorage; 꾸미기 상태 등 IndexedDB meta. 브라우저별 저장.
  • 서버 AI API는 요청 입력을 처리한다. 브라우저에 저장된 모든 기록을 자동으로 읽어 장기 기억하는 서비스가 아니다.
  • 호스팅 주소가 바뀌면 브라우저 저장소도 달라진다. Vercel 기록은 Render로 자동 이전되지 않는다. 전체 계정 동기화·일괄 백업/복구는 미제공이다.

입력·동의·결과 상태

  • 입력 팝업 닫기와 저장/전송을 구분한다. 작업 중 팝업 닫기·중복 전송을 제한하고, 미전송 내용이 있으면 이동 시 확인한다.
  • 생성/저장/복사 성공은 실제 비동기 작업 성공 이후에 안내한다. 실패 시 사용자가 입력을 다시 활용할 수 있어야 한다.
  • AI 전송 안내를 확인한 후 전송한다. 완료한 동의는 접어 보여주며 열람·철회할 수 있다. 새 작업에서 동의 상태가 초기화될 수 있으며 영구적인 계정 동의는 아니다.
  • 현재 무료 Gemini 설정은 개인정보·기밀 없는 가상/자작 대화를 사용하는 성인 대상이다. 실제 대화 무제한 업로드를 허용하는 표현을 쓰지 않는다.
  • AI 응답, 사전 작성 샘플, 사용자 입력을 구분한다. 샘플은 사용자의 실제 분석 결과로 표시하지 않는다.
  • 한도/연결 오류 시 지원 경로는 샘플 및 재시도 안내를 제공한다. 모든 API가 개인화된 샘플로 대체되는 것은 아니다. 복기·전사 실패는 실패를 알리고 원문을 보존해야 한다.
  • 조회 상태 configured는 키 설정 확인일 뿐 AI 응답 성공을 의미하지 않는다.

구현 제한

외부 파일은 2분·2.4MB 이내이며 직접 녹음은 최대 60초다. 짧은 코칭의 음성 입력은 최대 8초다. 같은 휴대폰의 전화·카카오톡 내용을 자동 수집하지 않는다. 언어 선택은 지원 대화 경로의 출력 언어 설정이며 앱 전체 번역·발음 평가 기능이 아니다.

6. IA 기준 기능명세

기능 ID의 ‘F’는 기능, 화면 ID는 3절 등록부와 연결된다. 아래 검수 기준은 자동 테스트와 실기기 검증을 구분해 적용한다. ‘완료’는 소스 구현을 뜻하며 운영 적용과 동일하지 않다.

F-01 · 실전 도움 / 평소 연습 진입

  • 화면/흐름: H-01 → P-01 → P-03 → 실전 L-01 또는 연습 P-04
  • 조건·입력: 첫 방문 또는 홈 진입. 실전/연습 선택. 진입 자체는 AI 호출 없음.
  • 처리·출력: 실전 도움을 강조, 평소 연습을 보조 행동으로 제공. 실전은 상대 말→힌트 과정을 먼저 설명한다.
  • 저장: D-04 관심 설정과 D-01 카드 재사용. 목적은 URL purpose=live로 복원.
  • 대안·오류·취소: 실전 진입 중 연습용 튜토리얼 자동 노출 금지. 알 수 없는 경로는 홈으로. 저장소 오류는 상태 안내.
  • 수용 기준: 실전·연습이 같은 목록을 쓰더라도 선택 후 주 버튼과 최종 화면이 다르며 새로고침 후 목적을 유지한다.
  • 구현 근거: HomeActions.tsx; ConversationWorkspace.tsx; workspace-navigation.ts
  • 검증 연결: learning-hub.test.cjs의 실전 목적 복원·튜토리얼 제외·코칭→같은 상황 연습 테스트; onboarding-ui.test.cjs

배포 후 필수 수동 검증 — 아직 통과로 표시하지 않음

  1. 시크릿 브라우저에서 실전 도움 주 버튼과 평소 연습 보조 버튼을 구분한다. 실전 선택→상황→목표 확인→코칭 화면까지 연습 튜토리얼 없이 진입하는지 확인한다.
  2. 가상 상대 말을 음성/문자로 입력해 다음 문장을 받고, 지킬 선을 어기지 않는지 확인한다. 녹음 종료부터 전사·제안 표시까지 시간과 실패를 기록한다. 인용 원문·실전→동일 카드 연습 연결도 확인한다.
  3. 가상의 업무 부탁 상황으로 AI 상대와 직접 두 번 답한다. 복기에서 원문 인용을 대조한다. 제안의 맥락·목표 준수도 사람이 확인한다.
  4. 같은 장면 재연습 시 이전 발화·목표·지킬 선 연결을 확인한다. 원본과 새 기록이 구분되어 남는지 확인한다.
  5. iPhone Safari와 Android Chrome에서 입력 팝업·키보드·닫기·스크롤·작은 글자와 버튼 겹침을 확인한다.
  6. 마이크 허용/거부·중지·무음·파일 초과·전사 오류에서 안내와 원본 보존을 확인한다. 다른 사람의 실제 대화를 시험 자료로 쓰지 않는다.
  7. 메시지 답장을 OS 클립보드에 복사해 다른 입력창에 붙여넣어 값과 성공 안내를 비교한다. 권한 거부 시 대체 복사를 확인한다.
  8. 저장 후 새로고침·재접속, 개별 삭제, 내려받기, 다른 출처 주소에서 데이터가 자동 보이지 않는 점을 확인한다.
  9. 한도 오류는 로컬 시뮬레이션으로 확인하고, 제한을 일부러 소진하지 않는다. 실제 AI는 할당량이 있는 조건에서 위 핵심 경로만 확인한다.

완료 판정은 ‘메뉴 동작’과 ‘실제 AI 코칭 품질’, ‘모바일 조작’을 각각 통과해야 한다. 현재 실제 브라우저 도구는 자동 승인 검토의 사용량 제한으로 실행되지 않아 모바일 시각·마이크·OS 클립보드 검증을 완료하지 못했다. 이를 다른 브라우저 수단으로 우회하지 않았다.
